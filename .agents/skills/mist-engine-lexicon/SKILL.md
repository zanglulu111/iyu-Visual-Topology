# 迷雾引擎辞典书写系统 (Mist Engine Lexicon System v2.0)

## **核心理念**

本系统专为**迷雾学派 (Mist School)** 的叙事生成引擎 (M0-M7) 及动力回路 (Circuits) 提供**极高浓度、超长篇幅、符号化逻辑**的理论文档书写。它不仅是功能说明，更是对叙事底层**拓扑学、精神分析与黑格尔辩证法**的深度论证，旨在将抽象哲学转化为可计算的叙事压力。

## **内容书写准则 (Mist Engine Standards)**

1. **维度与密度要求 (Volume & Density)**:
   - **核心位点 (M0-M7)**：单篇幅必须达到 **5000字以上**。
   - **动力回路 (Circuits)**：单篇幅必须达到 **4000字以上**。
   - 禁止使用软性、科普性语言，必须使用高密度的理论论证、逻辑推导和要素间的拓扑转化。

2. **哲学核准度 (Philosophical Rigor)**:
   - 必须将引擎位点的运作逻辑与**黑格尔（绝对否定性）、拉康（缺失、对象a、大他者、实在界）及齐泽克（视差、穿越幻象、少于无）**的核心概念进行本体论层面的“硬核耦合”。
   - **验证点**：M1 必须对应黑格尔的“绝对否定性”；M3 必须展现 $S \diamond a$ 的缝合逻辑；M4 必须论证符号秩序的虚构性。

3. **引擎工程化解算 (Engine Mapping)**:
   - **物质消解原则**：严禁在引擎位点中涉及纯粹的物质描述（如“缺钱”、“由于贫穷”）。所有物质现象必须映射为**“结构性坍塌”**或**“关系的断裂”**。
   - **参数族群**：必须对 `data/` 目录下的参数族谱（Group A-D）进行底层逻辑、生产语法与审美倾向的深度解析。

4. **数学/拓扑形式化 (Formalization)**:
   - 必须使用 **LaTeX** 编写位点间的动力学公式、引力模型或拓扑解算式。
   - 必须为每个位点分配唯一的**拓扑符号**（如 $、a、S_1、S_2、\↯$ 等）。

## **词条书写结构 (Standard Sectioning)**

### **1. 前置元数据 (Frontmatter)**
每个词条必须包含以下 YAML 字段：
```yaml
title: "MX：名称 (English Name) | 副标题"
id: "mist_mX"
category: "叙事生成引擎 (M0-M7)" # 或 "动力回路 (Circuits)"
formula_position: "MX" # 或 formula_components: ["M1", "M2"]
symbol: "$" # 拓扑符号
thinker: "迷雾学派 (Mist School)"
word_count_target: "5000+"
version: "v2.0"
```

### **2. 正文章节要求**
1. **一、 概念原典与本体论界定 (Ontological Definition)**:
   - 确立位点的先验地位，通过超长篇幅定义其“虚无”或“结构性”本质。
   - 强调其在迷雾“结构拓扑学”中的基石作用。

2. **二、 哲学史考古与理论同构 (Theoretical Isomorphism)**:
   - 重点论述与黑格尔/拉康/齐泽克理论的递归关系。
   - 必须通过“哲学考古”证明位点的必然性。

3. **三、 引擎位点动力学解析 (Engine Dynamics)**:
   - 拆解该位点在核心公式 `Story = ...` 中的交互。
   - 引入动力学参数（如“真空重力”、“撞击系数”、“缝合强度”）。
   - **必须包含 LaTeX 公式块。**

4. **四、 参数族谱与叙事生产映射 (Parametric Mapping)**:
   - **族群拆解**：对 Group A-D 进行深度逻辑解构。
   - **物质解算表**：必须包含一个三栏表格，展示“物质表象”向“引擎底层本质”的转化映射。

5. **五、 方法论制约与操作手册 (Methodology & Constraints)**:
   - 提供“本体论卫生学”警示、视差对比原则和具体的参数配置红线。

## **质量检测红线 (Redlines)**
- **禁止**出现任何廉价的、情感治愈性的结论。
- **禁止**简单列举大纲或使用列表式凑字数。
- **必须**使用加粗处理所有的核心逻辑转折与术语。
- **必须**在开头包含一段具有“神启感”的迷雾学派语录。
- **必须**使用 `[!IMPORTANT]` 或 `[!CAUTION]` 标记最高级别的创作禁忌。
