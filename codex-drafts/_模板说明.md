# 迷雾辞典 写作指南

## 使用方法

1. 在对应哲学家目录下，创建以概念 ID 命名的 `.md` 文件
   - 例：`lacan/l_mirror_stage.md`
   - 文件名必须与 `philosophy_refined.ts` 中的 concept `id` 一致

2. 按照以下格式写作（三个固定区块）：
   - `## 定义` ← 核心定义内容  
   - `## 类比` ← 拓扑类比与案例
   - `## 应用` ← 叙事引擎部署指示

3. 保存文件后，运行转换命令：
   ```
   npm run codex:build
   ```
   或者开启监听模式（保存即自动转换）：
   ```
   npm run codex:watch
   ```

```markdown
### 2. 第二个类比标题

```

## 三个区块说明

**## 定义**（对应 JSON 的 `definition` 字段）
- 哲学史坐标
- 底层逻辑剖析  
- 实在界的逻辑

**## 类比**（对应 JSON 的 `analogy` 字段）
- 2-3 个具体类比案例
- 物理、影视、数字世界的跨域映射

**## 应用**（对应 JSON 的 `application` 字段）
- M-S 结构映射
- 污迹部署
- 经典文本佐证
- 实战操作指示
