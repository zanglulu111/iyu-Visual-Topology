# 迷雾学派小红书运营规划 v1

## 1. 账号定位

账号一句话：
用高设计感哲学海报，把哲学家、理论概念和当代生活症候做成可收藏的视觉图鉴。

核心人设：
- 不是传统哲学科普号，而是“哲学视觉策展人 + 当代症候翻译器”。
- 语言保持锋利、漂亮、可懂：一半像展览说明，一半像小红书笔记。
- 每条内容都让用户获得一个可转发的身份标签：我终于知道自己为什么这样了。

目标人群：
- 人文社科、艺术设计、AIGC、影像、心理学、文学爱好者。
- 喜欢拉康、齐泽克、马克思、黑格尔，但不一定读原典的人。
- 喜欢“高级感视觉 + 一句话击中”的收藏型用户。

内容承诺：
- 每张图不只是好看，而是一个思想入口。
- 每个概念不做学院定义，而做成当代生活里的可见症状。

## 2. 内容资产分层

现有资产可以拆成四类：

1. 哲学家肖像海报  
用途：账号门面、人物系列、合集封面、知识收藏。

2. 哲学概念海报  
用途：主要日更内容。Lacan / Hegel / Zizek / Marx 四条主线。

3. 主题合集  
用途：拉收藏、拉关注。例如“打工人会用到的 9 个齐泽克概念”“恋爱中最拉康的 12 个瞬间”。

4. 运营索引页  
用途：从生产表升级为发布中控台，管理发布状态、标题、正文、标签、平台链接和合集归属。

## 3. 栏目矩阵

### A. 今日哲学家

形式：1 张人物海报 + 3 行介绍 + 1 个代表问题。

例子：
- 尼采：你不是想变强，你是还没学会承受自己的混乱。
- 孔子：所谓礼，不是规矩，而是关系不崩坏的技术。
- 康德：自由不是想做什么，而是能不能给自己立法。

频率：每周 2 条。

### B. 今日概念

形式：1 张概念海报 + “一句话解释” + “生活场景” + “保存理由”。

例子：
- 对象小 a：你真正想要的，不是那个东西，而是它承诺的那个缺口。
- 犬儒理性：你知道它有问题，但你还是照做。
- 美丽灵魂：不行动，是为了保持自己永远正确。

频率：每周 3-4 条，是主力栏目。

### C. 症候图鉴

形式：把理论概念翻译成当代情绪、亲密关系、职场、消费、互联网生活。

选题方向：
- 为什么越刷越空虚：剩余享乐、死亡驱力、超我享乐命令。
- 为什么你总想被喜欢：大他者的欲望、凝视、镜像阶段。
- 为什么打工像灵魂外包：异化劳动、资本主义话语、客观暴力。

频率：每周 2 条。

### D. 电影与流行文化理论

形式：用齐泽克式文化分析做轻入口。

选题方向：
- 鲨鱼为什么不是鲨鱼：怪物是社会矛盾的容器。
- 泰坦尼克为什么好哭：灾难给爱情提供崇高舞台。
- 黑暗英雄为什么需要谎言：高贵谎言与社会信仰。

频率：每周 1-2 条。

### E. 哲学合集

形式：9 宫格、12 张卡、系列目录。

合集方向：
- 拉康 100 个概念收藏路线。
- 黑格尔 90 个概念入门路线。
- 齐泽克 90 个当代症候。
- 马克思 58 个资本主义诊断。
- S 级哲学家肖像合集。

频率：每周 1 条，用来拉收藏。

## 5. 单条笔记结构模板

标题公式：
- 你不是 X，你是在 Y。
- 这个概念解释了我最近的精神状态。
- 如果你总是 X，可能你需要理解 Y。
- 一张图解释：为什么 X 不是 X。
- 哲学家早就说过：X 的本质是 Y。

正文结构：
1. 一句击中：
   “你以为你想要那个东西，其实你想要的是它制造的缺口。”
2. 概念解释：
   “拉康把这个缺口称为对象小 a。”
3. 生活翻译：
   “它可以是一段关系、一个包、一条消息、一个迟迟不来的认可。”
4. 视觉说明：
   “所以这张海报里，商品不是被看见，而是在反过来凝视消费者。”
5. 互动问题：
   “你最近被哪个对象小 a 牵着走？”

## 6. 索引页优化方向

当前索引页已经有：搜索、时期筛选、级别筛选、左翼/非欧美筛选、CSV 导出。

下一步应升级为发布中控台：

新增字段：
- posterStatus：未生成 / 已生成 / 已精选 / 已发布 / 待重做
- platform：小红书 / 视频号 / 即刻 / B站 / 网站
- series：今日概念 / 今日哲学家 / 症候图鉴 / 电影理论 / 合集
- publishTitle：小红书标题
- caption：正文草稿
- tags：发布标签
- publishDate：计划发布日期
- assetPath：海报文件路径
- xhsUrl：发布后链接
- priority：首发 / 常规 / 合集备用

新增视图：
- 海报墙：用缩略图浏览，不只看表格。
- 发布日历：按周查看要发什么。
- 栏目看板：按栏目拖拽状态。
- 哲学家索引：人物线。
- 概念索引：Lacan / Hegel / Zizek / Marx 四大概念线。

新增操作：
- 一键复制小红书标题。
- 一键复制正文和标签。
- CSV/JSON 导出发布计划。
- 已发布链接回填。
- 按“未发布高优先级”筛选。

## 7. 30 天目标

不要先追求爆款，先追求稳定识别度。

数量目标：
- 30 天发布 45-60 条。
- 其中单图概念 30 条，人物肖像 8 条，合集 6 条，账号说明/路线图 3 条。

质量目标：
- 每条只讲一个概念。
- 每条都能被收藏。
- 每 7 天复盘一次：收藏率、评论关键词、哪类标题被点开。

账号识别语：
“把哲学做成可收藏的精神图鉴。”
