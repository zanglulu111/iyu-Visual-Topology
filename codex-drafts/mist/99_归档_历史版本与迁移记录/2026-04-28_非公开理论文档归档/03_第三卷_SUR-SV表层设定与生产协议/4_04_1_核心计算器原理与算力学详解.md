# 4_04_1：迷雾引擎核心计算器原理与算力学详解

> “计算器不是把故事变成数字游戏，而是把数字当作外科夹具，防止生成器把悲剧缝回廉价圆满。” —— 迷雾学派

---

## 零、版本裁定

本文档取代旧 v2.0 计算器说明。旧文档中的 `M4X / M5X / M2X / SUR4X` 已从 active 理论中移除：

- `M4X` 不再作为受压迫等级。
- `M5X` 不再作为行动流速等级。
- `M2X` 不再作为创伤穿透等级。
- `SUR4X` 不再作为物理阶层阻力。

最终版计算器只承认三层：

```text
M 定义结构原因。
SUR 定义现象显现。
SV 定义工程展开。
```

计算器的任务，是把这三层编译为可执行的生成约束，而不是给每个表层元素追加强度旋钮。

---

## 一、计算器总管线

迷雾计算器的运行分为五个阶段：

1. **结构输入**：读取 M0-M7A/M7B、SUR1-SUR10 + SUR-END、SV1/SV2、世界法则等用户配置。
2. **M 轴解算**：根据 M1-M5 的组别重力、M0 操作系统修饰、SUR10X 信念裂度，计算叙事张力。
3. **闭合校验**：检查 M6 代价是否足以承载当前张力，并保留红线审查接口。
4. **指令编译**：将 M 轴硬指令、SUR 表层语义、SV 工程展开与世界法则整理成多级 payload。
5. **生成投射**：把 payload 交给大模型，使其在明确约束下展开故事。

---

## 二、核心张力公式

最终公共公式保持为：

```text
Story = M0 {[(M1↔M2↔M3)/M4]×M5} ⇒Act M6 → (M7A◇M7B) ↺ M1'
```

计算器内部将它压缩为张力解算：

```text
N = G(M1) + G(M2) + G(M3) × μM0(M3) × λ(SUR10X)
D = max(G(M4) × μM0(M4) × W, ε)
T = (N / D) × G(M5) × μM0(M5)
```

其中：

| 符号 | 含义 |
| --- | --- |
| `G(Mx)` | M 词条所在组别的基础重力 |
| `μM0(M3)` | M0 对幻想透明度/毒性的修饰 |
| `μM0(M4)` | M0 对大他者有效性的修饰 |
| `μM0(M5)` | M0 对行动驱力的修饰 |
| `λ(SUR10X)` | 人物与开场信念语言的表层粘合系数 |
| `W` | M4 作为阻断项的固有镇压权重 |
| `ε` | 防止分母归零的最低限 |

这套公式说明：**只有 SUR10X 以表层系数接入 M3 的显影程度**。其他 SUR 参数不参与浮点计算，它们只进入 payload 的表层语义层。

---

## 三、M0：计算发生的操作系统

M0 不是一个普通参数，而是公式运行的定义域。它修改括号内运算的规则：

| M0 大类 | 计算效果 | 叙事实效 |
| --- | --- | --- |
| 神经症 | M4 有效，M5 被延宕，M3 透明度下降 | 主体承认法的存在，行动常被循环、犹豫、症状化拖慢。 |
| 倒错 | M4 被折扣，M5 放大，M3 更粘稠 | 主体劫持法的位置，通过仪式化行动榨取快感。 |
| 精神病 | M4 缺如或外投，除法关系失稳 | 现实与幻象边界破裂，阻断不再以正常法律形式运行。 |
| 自闭 | 符号接入减弱，M5 与 M3 全面衰减 | 外部信号被过滤、归档、隔离，行动呈现封闭重复。 |

计算器必须首先解析 M0，再解释 M1-M7B。若某个 M 词条在替换任意 M0 后仍以完全相同方式运行，说明 M0 未真正生效。

---

## 四、M7A/M7B：张力走向的终端校正

M7A 与 M7B 不再合并为旧 M7，也不归入 SUR-END。

| 位点 | 计算职责 | 理论职责 |
| --- | --- | --- |
| M7A | 对张力走向进行象征裁决校正 | 故事结束后，回溯性改变整条链条的意义。 |
| M7B | 对终态余味进行实在残留校正 | 保留无法被意义消化的身体、物件、空间或感官残余。 |
| SUR-END | 不参与意义校正 | 只描述最后可见画面与外部收场事件。 |

因此，“主角死在雪地里”可以是 SUR-END；“这一死回溯性证明他从未真正逃出父法”属于 M7A；“雪地里仍有一只手在无意识抽动”属于 M7B。

## 五、SUR 与 SV 在计算器中的位置

### 5.1 SUR：表层语义层

SUR1-SUR10 + SUR-END 作为表层配置进入 payload：

- SUR1 定义类型节奏。
- SUR2 定义世界材质。
- SUR3 定义时空坐标。
- SUR4 定义社会形态。
- SUR5 定义对象预设。
- SUR6 定义空间容器。
- SUR7 定义选角呈现。
- SUR8 定义年龄阶段。
- SUR9 定义职业身份。
- SUR10 定义开场信念语言。
- SUR-END 定义最后可见收场。

它们大多数不参与张力浮点计算，因为它们不是原因层。它们告诉生成器“穿什么皮”，不告诉生成器“为什么必须如此”。

### 5.2 SUR10X：唯一保留表层系数

SUR10X 只接入一个位置：M3 的表层显影。

```text
SUR10X = 人物与开场信念语言的粘合强度
```

虔信会让 M3 的幻想更容易被人物语言包住；决裂会让语言无法再稳定遮蔽经验。但 SUR10X 不产生 M3，不解释欲望，也不裁决结尾。

### 5.3 SV：工程指令层

SV1/SV2 不参与核心张力公式，而是进入指令编译：

- SV1 指定结构模板、信息释放顺序、段落组织。
- SV2 指定故事体量、密度、篇幅和展开尺度。

SV 是显影工程，不是心理原因。

## 六、代价守恒与红线审查

计算器必须持续维持一条硬规则：

```text
张力越高，M6 代价越不能轻。
```

如果张力已经要求结构性毁损，而 M6 却只给轻微损失，生成器会滑向廉价剧情。代价审查的目的，是防止“雷声大雨点小”。

最终版红线不再围绕旧 X 参数，而围绕三类问题：

| 红线类型 | 触发 |
| --- | --- |
| M 轴互斥 | M0 的临床结构与 M5 行动方式、M3 幻想状态、M4 有效性发生硬冲突。 |
| 代价失衡 | 当前张力要求更重 M6，但配置的代价过轻。 |
| 表层越权 | SUR 或 SV 反向改写 M1/M3/M4/M6/M7A/M7B。 |

## 七、Payload 四层结构

最终 payload 应按权限分层：

| 层级 | 内容 | 优先级 |
| --- | --- | --- |
| 全局宪法 | 禁止机械降神、禁止廉价治愈、禁止角色总结意义 | CRITICAL |
| M 轴硬指令 | M0 覆写、M1-M7B 逻辑、M7A/M7B 双结项 | CRITICAL/HIGH |
| SV 工程指令 | 结构模板、体量密度、信息释放顺序 | HIGH |
| SUR 表层语义 | 类型、场域、社会外壳、对象、身份、空间、收场画面 | NORMAL/HIGH |

这一排序体现最终宪法：

```text
M 定义结构原因。
SUR 定义现象显现。
SV 定义工程展开。
SUR-END 定义最后可见画面。
M7A 定义意义裁决。
M7B 定义实在余痕。
```
