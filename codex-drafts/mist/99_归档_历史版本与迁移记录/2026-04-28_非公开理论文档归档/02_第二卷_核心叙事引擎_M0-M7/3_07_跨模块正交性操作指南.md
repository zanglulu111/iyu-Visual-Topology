# 跨模块正交性操作指南

> "同一个词——'虚无'——在 M1 是引擎的燃料，在 M4 是阻断的裂隙，在 M6 是代价的切口，在 M7A 是裁决的名字，在 M7B 是余痕的底色。如果你分不清它们，你的叙事就是一锅粥。" —— 迷雾学派

---

## 第一部分：存在维度跨模块投射指南 (P1-2)

### 1.1 问题定义

"虚无/存在"是人类叙事的永恒母题。在迷雾引擎中，这个母题在五个模块中同时出现——但它在每个模块中的**拓扑功能完全不同**。如果创作者把它们混为一谈，引擎将产生语义短路。

### 1.2 五维投射总览

| 模块 | 存在维度的拓扑角色 | 隐喻 | 禁止混淆 |
| :--- | :--- | :--- | :--- |
| **M1 缺失($)** | 存在的**原始空洞** | 宇宙大爆炸之前的"无" | ≠ M6 的代价（M1 的空洞是先验的，它不是被"切掉"的） |
| **M2 遭遇(↯)** | 存在的**突然暴露** | 地板消失，你看到了地板下的虚空 | ≠ M1 的空洞（M2 是看到空洞的那个事件，不是空洞本身） |
| **M4 阻断(∄A)** | 存在的**制度化否认** | "请勿直视太阳"的牌子 | ≠ M2 的暴露（M4 是阻止你看到虚空的过滤器，不是暴露虚空的穿刺） |
| **M6 代价(−Φ)** | 存在的**不可逆减法** | 外科手术切掉了一个器官 | ≠ M1 的空洞（M6 的减法是叙事中发生的事件，M1 的空洞是先于一切的） |
| **M7A 裁决(◇)** | 存在的**回溯命名** | 医生在病历上写下诊断名 | ≠ M7B 的余痕（M7A 是给整段经历命名，不是身体留下的纹理） |
| **M7B 圣状(Σ)** | 存在的**余痕沉积** | 手术后伤疤上长出的新皮肤 | ≠ M6 的切口（M7B 是切口愈合后的纹理，不是切口本身） |

### 1.3 配置示例：角色"虚无主义者"的跨模块拆解

假设一个角色的核心主题是"存在的无意义"。以下是正确的跨模块分配：

```
M0: 忧郁症协议(C3) — 生命力被剥夺的场域，世界呈现灰色调恒温
M1: "我从一开始就不应该存在" — 原初缺失的坐标
M2: "那天他对我说'你出生是个意外'" — 穿刺的具体事件
M3: "如果我能找到一个真正需要我的人(◇)" — 补偿空洞的幻象矢量
M4: "社会告诉你'活着就有意义'" — 阻断你直面虚无的过滤器
M5: "他用一种缓慢的、沉降的姿态走向每一段关系" — 驱力的运动质感
M6: "他终于如愿以偿被需要了——但发现被需要和被爱是两回事(−Φ)" — 被切掉的幻象
M7A: "这是一个关于空洞无法被他者填满的故事(◇)" — 象征裁决
M7B: "他在废墟中开始用手指在沙地上画圆圈(Σ)" — 圣状的感官沉积
```

> [!WARNING]
> **常见错误**：把 M1 和 M6 混为一谈。M1 的"空洞"是先验的（你出生就有），M6 的"减法"是叙事中发生的。两者的关系是：M6 的减法**暴露**了 M1 的空洞——它不创造空洞，它只是撕开了遮蔽空洞的幻象。

### 1.4 "虚无"在不同协议栈(M0)下的色温变化

| M0 协议 | "虚无"的呈现方式 |
| :--- | :--- |
| 神经症(A) | 虚无被体验为**焦虑** — "一定有什么东西不对，但我说不出来" |
| 性倒错(B) | 虚无被体验为**被否认的缺口** — "没有什么是空的，我可以用[物/仪式]填满它" |
| 精神病(C) | 虚无被体验为**碎裂/崩塌** — 虚无不是抽象概念，而是具体的、正在发生的解体 |
| 孤独症(D) | 虚无**不被体验** — 因为大他者从未建立，所以"缺失"这个概念本身不存在 |

## 第二部分：跨模块编码规则 (P1-3)

### 2.1 问题定义

同一个叙事事件（如"背叛"）在装填词库时可能同时触及多个模块。如果创作者不遵守编码规则，会导致：
- 同一内容在不同模块中重复出现
- 模块之间的正交性被破坏
- AI 生成时产生语义回环

### 2.2 单一事件的跨模块注册规则

**核心原则：一个事件只在一个模块中被"完整登记"，其他模块只引用其拓扑投影。**

以"至亲背叛"为例：

| 模块 | 注册内容 | 注册方式 |
| :--- | :--- | :--- |
| **M2**（主注册点） | "背叛"事件的完整描述：A面/B面/关键张力 | **完整词条** — 这是事件的"户籍所在地" |
| M1 | "背叛"暴露的原初缺失坐标 | **引用**：M1 不描写背叛事件，而是描写"由于背叛而显露的那个一直存在的空洞" |
| M3 | "背叛"催生的幻象矢量 | **引用**：M3 不描写背叛事件，而是描写"背叛之后主体开始追逐什么来填补" |
| M6 | "背叛"造成的不可逆代价 | **引用**：M6 不描写背叛事件，而是描写"由于信任的丧失，主体永远失去了什么" |

### 2.3 字段命名的正交性清单（v4.1 双结项版）

| 模块 | 字段名 | 符号来源 | 拓扑功能 |
| :--- | :--- | :--- | :--- |
| M1 | `缺失($)` | $ = 被划杠的主体 | 先验的空洞坐标 |
| M2 | `实在界入侵(Tuche)` | Tuche = 偶然撞击 | 象征秩序的外部穿刺 |
| M3 | `幻象破绽(◇)` | ◇ = 幻象公式 $◊a 的关系算子 | 幻象剧本的内部逻辑矛盾 |
| M4 | `秩序的裂隙(∄A)` | ∄A = 大他者不存在 | 大他者过滤系统的失效点 |
| M5 | `驱力脉动(Trieb)` | Trieb = 弗洛伊德驱力 | 驱力围绕空洞旋转的不可停转 |
| M6 | `代价切口(−Φ)` | −Φ = 被减去的阳具能指 | 叙事中不可逆的结构性减法 |
| M7A | `象征裁决(◇)` | ◇ = Point de Capiton | 叙事链条的回溯性意义锚定 |
| M7B | `实在余痕(Σ)` | Σ = Real Residue | 减法之后的存在纹理沉积 |

### 2.4 装填校验清单（给 AI / 创作者）

在装填任何模块词条时，依次检查：

1. **正交性检查**：这条词条是否"只回答了这个模块应该回答的问题"？
   - M1 只回答"缺什么"
   - M2 只回答"遭遇了什么"
   - M3 只回答"追逐什么"
   - M4 只回答"什么在阻止"
   - M5 只回答"怎么运动"
   - M6 只回答"失去了什么"
   - M7A 只回答"这一切变成了什么故事"
   - M7B 只回答"留下了什么"
2. **因果性检查**：这条词条的 core 字段是否描写了另一个模块的内容？
   - ❌ M2 词条中描写了主角"开始寻找真爱"→ 这是 M3 的内容
   - ❌ M5 词条中描写了主角"失去了一切"→ 这是 M6 的内容
3. **事件归属检查**：同一个叙事事件是否只在一个模块有完整登记？
4. **M0 引力检查**：这条词条是否被 M0 协议栈正确过滤？（如：精神病协议下的 M2 不应出现"反思性的痛苦"）

## 第三部分：M3/M5 边界术语统一 (P2-1)

### 3.1 M3 与 M5 的拓扑区别

| | M3 幻象的运动 | M5 驱力的运动 |
| :--- | :--- | :--- |
| **回答的问题** | "你追逐什么？" | "你怎么走路？" |
| **拓扑角色** | **矢量**（方向/目标） | **姿态**（步态/质感） |
| **公式位置** | 分子：被除 | 乘数：后天加速/减速 |
| **与欲望的关系** | 欲望的**剧本** | 欲望的**肌肉** |
| **类比** | GPS 导航上的目的地坐标 | 脚下踩的是跑步机还是泥地 |
| **时间性** | 指向未来：**"我要到达那里"** | 指向当下：**"我此刻正在这样移动"** |
| **可意识性** | 部分可意识（"我想要X"） | 几乎不可意识（驱力是自动运转的引擎） |

### 3.2 高危边界案例

| 叙事事件 | M3（幻象矢量） | M5（驱力姿态） |
| :--- | :--- | :--- |
| "他不断换工作" | "寻找那个让我觉得有意义的事业"（追逐的目标） | "他靠近一切东西的方式都像是在用手指试探热锅的温度——碰一下就弹回来"（运动的质感） |
| "她拒绝所有求婚" | "等待一个值得我交出全部的人"（幻象中的完美对象） | "她的身体在说是，但手在最后一刻总是缩回去——不是犹豫，是肌肉记忆"（驱力的回避弧线） |

> 永远记住——模块之间的正交性不是"分类的便利"，而是**拓扑学的必然**。

> 把它们搞混，不是审美问题——是引擎故障。
