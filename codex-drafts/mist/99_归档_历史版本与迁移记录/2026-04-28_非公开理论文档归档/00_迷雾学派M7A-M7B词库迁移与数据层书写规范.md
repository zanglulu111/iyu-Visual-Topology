# 迷雾学派 M7A-M7B 词库迁移与数据层书写规范

> “结尾不是故事停止的地方，而是意义试图封口、实在拒绝被封口、世界只剩最后一个画面的地方。”

本文是 `codex-drafts/mist` 内针对 **M7A / M7B / SUR-END 数据层** 的跨卷执行规范。它不服从旧“卷一到卷五”的编辑秩序；相反，卷结构只是书写陈列方式，不能决定引擎本体。若任何旧词条、旧卷目录、旧代码注释、旧 SUR11 命名与本文冲突，以本文为准。

最终公式保持：

```text
Story = M0 {[(M1↔M2↔M3)/M4]×M5} ⇒Act M6 → (M7A◇M7B) ↺ M1'
```

其中：

```text
M7A = 象征裁决 / retroactive verdict / quilting point
M7B = 实在余痕 / real residue / symptomatic remainder
SUR-END = 显性收场 / visible ending / last frame
```

三者不是同一件事的三种说法，而是三种注册域。**M7A 属于象征界，负责判定故事“成为了什么”；M7B 属于实在界，负责保存裁决之后仍不能被解释的硬块；SUR-END 属于表层世界，只负责最后一帧看见什么。**

> [!IMPORTANT]
> 数据层维护的最高纪律：**M7A 裁决意义，M7B 保存余痕，SUR-END 显示最后一帧。任何词条不得把三者互相冒充。**

## 1. 数据路径的最终解释

当前工程为了兼容旧导入，保留了一些历史路径。路径名不是本体论真理，语义口径才是。

| 数据路径 | 当前语义 | 允许保留的兼容名 | 维护原则 |
| --- | --- | --- | --- |
| `data/engine_core/m7a/` | **M7A 象征裁决词库** | `M7A_VERDICTS` | 可直接作为最终命名 |
| `data/engine_core/m7/` | **M7B 实在余痕词库** | `M7_OUTCOMES`, `OUTCOMES_GROUP_*` | 导出名可为兼容保留，但注释与文案必须写成 M7B |
| `data/engine_surface/SUR11/` | **SUR-END 显性收场库** | `SUR11_DATA` | 路径暂时兼容，UI/理论只称 SUR-END |

这意味着，`m7/` 目录中旧的 `OUTCOMES` 不是“结局裁决”，而是 **M7B residual outcomes**：它描述故事完成之后仍残留在身体、关系、空间和语言里的东西。它可以叫 outcome 是因为历史代码需要，但不能在理论上继续承担“故事意义”的工作。

## 2. M7A：象征裁决的词条法

M7A 的问题不是“最后发生了什么”，而是：

```text
前面的一切在终点被回溯性地判定为什么？
```

M7A 是 **缝合点(◇)**。它把 M1-M6 的运动重新排序，使读者在终点回头看开头时，发现故事的结构意义已经变了。一个合法的 M7A 词条必须具备三层动作：

1. **判词性**：它必须能说出一种结构判定，例如幻灭、同化、穿越、毁灭、重结、错置、空心胜利、正交逃逸。
2. **回溯性**：它必须回头改写 M1-M6 的含义，不能只描述终点情绪。
3. **象征性**：它必须处理“意义如何被缝合”，而不是处理身体后遗症或最后画面。

合法句式：

```text
M3 被揭示为……
M5 被回溯性地证明为……
M6 的代价并非……而是……
这个故事最终不是……而是……
缝合点(◇)：……
```

非法句式：

```text
他最后站在海边。              # 这是 SUR-END
他以后闻到雨味就发抖。        # 这是 M7B
这个结局很治愈/很刀/很爽。    # 这是表层情绪，不是裁决
```

M7A 可以有 A面/B面，但 A面/B面不是“好结局/坏结局”。它们是同一裁决的两种读法：**裁决必须成立，同时必须暴露它的代价。**例如“正交逃逸”的 A面是系统失效，B面是棋盘外的绝对孤独；二者不是两个结局，而是同一个裁决的视差。

## 3. M7B：实在余痕的词条法

M7B 的问题不是“这个故事说明了什么”，而是：

```text
意义已经被 M7A 缝合之后，还有什么东西不肯被缝进去？
```

M7B 是 **实在余痕(Σ)**。它不是主题，不是寓意，不是最后事件，而是裁决之后仍然卡在主体身上的不可消化物。它可以表现为身体症状、重复动作、感官触发、沉默、关系形变、空间污染、他者感染、语言结晶、记忆错位。M7B 的关键不是“深刻”，而是 **不能被解释彻底吃掉**。

合法句式：

```text
尘埃落定后，主体仍然……
身体已经忘不了……
他知道没必要，但手还是……
某种气味/光线/动作把一切带回来……
实在余痕(Σ)：……
```

非法句式：

```text
所以他获得了救赎。        # M7A 越权
这证明反抗终于胜利。      # M7A 越权
最后镜头停在婚礼上。      # SUR-END 越权
一切都被解释清楚了。      # 取消 M7B
```

M7B 的 A面/B面也不能写成道德评判。A面不是“积极治愈”，B面不是“消极创伤”。A面是余痕作为生存证据、忠诚、敏感度、经验密度的一面；B面是同一余痕作为绑架、重复、冻结、传染、异化的一面。二者必须共存，不能被其中一面解决。

M7B 的核心字段建议统一使用：

```text
| 实在余痕(Σ): ...
```

不再使用旧的“圣状余痕”作为通用标签。若某个词条确实涉及拉康意义上的 sinthome，可以在正文解释“症状/圣状结构”，但字段标签仍使用 **实在余痕(Σ)**，以免与旧 M7 体系混淆。

## 4. SUR-END：显性收场的词条法

SUR-END 的问题只有一个：

```text
观众最后看见了什么？
```

SUR-END 是表层可见事件，不是故事意义，不是身体余味，不是道德判决。它可以描述婚礼、葬礼、爆炸、远行、重逢、分离、审判、街道、尸体、空房间、清晨、车站、海边、门被关上、灯还亮着。它不能决定这些画面“意味着”什么。

合法句式：

```text
最后画面停在……
主体走入……
门关上后……
镜头留在……
众人看见……
```

非法句式：

```text
最后他真正自由了。            # M7A
这是一场救赎。                # M7A
他之后再也无法闻到海风。      # M7B
观众明白人生没有意义。        # M7A
```

SUR-END 可以与 M7A/M7B 发生兼容性检查，但不能反向修改它们。例如：

```text
SUR-END = 主角活下来
M7A = 反抗被证明只是更深的同化
M7B = 他每次听见掌声都会短暂失聪
```

这三者完全可以共存。活下来不是救赎；活下来只是可见事实。意义由 M7A 判定，余痕由 M7B 保存。

## 5. 旧词库迁移判定表

迁移旧 M8、旧 M7、旧 SUR11 时，不看文件名，先看句子的功能。

| 旧内容的主要动作 | 新归属 | 处理方式 |
| --- | --- | --- |
| “最终证明……”“原来一切都是……”“不是 A 而是 B” | M7A | 改写为象征裁决，补上 M1-M6 回溯链 |
| “身体仍然……”“手还是……”“闻到/听到/梦到/重复……” | M7B | 改写为实在余痕，保留不可解释性 |
| “最后镜头……”“结尾画面……”“众人看到……” | SUR-END | 剥离意义，只保留可见事件 |
| 同时包含意义判定与身体残留 | M7A + M7B | 拆成两个词条或两个字段，不得混写 |
| 同时包含最后画面与意义判定 | SUR-END + M7A | SUR-END 留画面，M7A 留判词 |
| 同时包含最后画面与身体后效 | SUR-END + M7B | SUR-END 留画面，M7B 留余痕 |

迁移时最常见的错误是把“结局很悲惨”误判为 M7A。悲惨不是裁决；悲惨只是情绪色调。M7A 必须回答：**悲惨在结构上证明了什么？**另一种错误是把“开放式结尾”误判为 M7B。开放不是余痕；开放只是 SUR-END 的一种可见收场方式。M7B 必须回答：**开放之后，什么东西在主体或世界里继续疼、继续重复、继续污染？**

## 6. 数据层字段的最小合格标准

### 6.1 M7A 词条最小标准

每个 M7A 词条至少要能定位：

```text
id: m7a_...
name: 裁决名
group: 裁决族群
def: 这个裁决如何判定故事
core: A面/B面 + 缝合点(◇)
topology: M1-M6 如何被回溯性重排
directive: 亮面/暗面/张力面如何呈现裁决
```

M7A 的 `core` 必须出现或等价包含：

```text
缝合点(◇)
M1/M2/M3/M4/M5/M6 至少两个位点的回溯解释
```

### 6.2 M7B 词条最小标准

每个 M7B 词条至少要能定位：

```text
id: res_...
name: 余痕名
group: 余痕族群
def: 尘埃落定后残留了什么
core: A面/B面 + 实在余痕(Σ)
topology: 余痕如何沉积在身体/关系/空间/语言中
directive: 亮面/暗面/张力面如何保留不可消化性
```

M7B 的 `core` 必须出现或等价包含：

```text
实在余痕(Σ)
尘埃落定后 / 仍然 / 停不下来 / 身体记得 / 无法翻译 / 无法关闭
```

### 6.3 SUR-END 词条最小标准

SUR-END 词条应定位：

```text
id: surface ending id
name: 可见收场类型
group: 可见事件族群
def: 最后画面或终端事件
core: 画面如何收束，不解释意义
```

SUR-END 的 `core` 不应出现：

```text
救赎 / 堕落 / 超越 / 虚无 / 证明 / 意味着 / 真正自由 / 获得意义 / 创伤余痕
```

若旧 SUR11 项目中出现这些词，说明它含有 M7A 或 M7B 内容，必须拆离。

### 6.4 SUR5 词条最小标准

SUR5 语义上读作 **SUR-OBJ 对象预设库**。它与 SUR-END 同属表层预设：SUR5 问“故事追什么物”，SUR-END 问“最后看见什么”。SUR5 词条应定位：

```text
id: surface object id
name: 对象名称
group: 对象族群
def: 可被追寻、争夺、交换或保护的对象
core: 对象如何作为表层锚点，不解释欲望来源
```

SUR5 的 `core` 不应出现：

```text
救赎 / 复仇 / 真理 / 超脱 / 自由 / 证明 / 意味着 / 终极代价 / 象征裁决 / 实在余痕
```

若旧 SUR5 项目中出现这些词，说明它把 M3、M6、M7A 或 M7B 的工作提前写进了表层对象，必须拆离。合法写法是“门禁卡、旧录音、黑箱、冷钱包、项圈钥匙、种子匣”；非法写法是“获得自由、完成复仇、发现真理、抵达超脱”。

## 7. 族群结构的最终读法

当前 M7B 数据层的五组可以保留，但读法必须统一为“余痕族群”，而非“结局族群”：

| 族群 | 新读法 |
| --- | --- |
| A. 隐秘的裂痕 | 语言无法抵达的内部残留 |
| B. 凝固的图腾 | 余痕凝结为物、句子、地点、感官锚点 |
| C. 死锁的齿轮 | 余痕变成停不下来的重复运动 |
| D. 异化的倒影 | 余痕改写主体形状、阈值、姿态与感知 |
| E. 蔓延的余烬 | 余痕外溢到他者、空间、代际与关系网络 |

这五组不是五种结局，而是五种 **实在残余的沉积方式**。它们可以附着在任何 M7A 裁决之后。例如同一个 M7A“空心的圣杯”，可以搭配 M7B“无名之重”“语言凝核”“强迫性确认”“信任坍塌”“沉默传染”。这正是 M7A/M7B 双结项的生产力：**同一种意义裁决，可以拥有不同的实在余痕；同一种余痕，也可以服务于不同的象征裁决。**

## 8. 最终红线

> [!CAUTION]
> 以下错误会直接破坏迷雾引擎的终点逻辑。

1. **禁止把 M7A 写成剧情总结**：M7A 不是“主角最后怎样了”，而是“全部事件回头看被判定为什么”。
2. **禁止把 M7B 写成主题升华**：M7B 不是“因此我们学会了什么”，而是“学会之后仍然有什么东西学不会”。
3. **禁止把 SUR-END 写成意义裁决**：最后一帧不是结论，只是可见事实。
4. **禁止让旧 M8 以新名字复活**：旧 M8 的有效部分已经进入 M7A；公开引擎保持 M0-M7。
5. **禁止让旧 SUR11 继续拥有大结局权力**：旧 SUR11 只能作为 SUR-END 数据路径兼容存在。
6. **禁止用治愈闭合 M7B**：余痕可以被温柔对待，但不能被廉价治好。
7. **禁止用含混冒充深刻**：M7B 不是模糊，M7A 不是谜语。一个负责硬判词，一个负责硬残留。

最终执行口令：

```text
M7A 问：这到底成为了什么故事？
M7B 问：这个判定之后还有什么东西剩下？
SUR-END 问：最后一帧看见什么？

三问必须同时回答。
三答不得彼此冒充。
```
