# 归档说明

本目录用于放置不再承担 active theory 解释权的材料。

归档不是删除，也不是否定旧稿价值。归档的作用是保护当前理论入口，使旧命名、旧结局协议、一次性工程报告或无理论归属的外部素材不再反向干扰最终定稿。

## 应放入本目录的材料

1. 旧 M8、旧 M7、旧 SUR11 等已完成迁移的历史说明。
2. 只记录某次代码、UI、词库同步的临时报告。
3. 已被 M7A/M7B/SUR-END 体系取代的旧结局模板。
4. 旧第五卷概念辞典占位稿，包括只复述拉康、黑格尔、齐泽克概念而没有生产功能的词条。
5. 有参考价值但不再是当前理论口径的草稿。

## 不应放入本目录的材料

1. 仍在 active corpus 中承担定义功能的总纲、公式、位点词条、SUR/SV 协议。
2. 已被卷一、卷二或卷三吸收并承担 active 定义功能的方法论材料。
3. 与迷雾学派完全无关的项目素材。此类材料应移出 `codex-drafts/mist`。

## 当前归档原则

如果一份材料的主要价值是“说明旧版本为什么被替换”，放入这里。

如果一份材料的主要价值是“定义当前理论如何运行”，保留在 active corpus，并在总目录中登记。
