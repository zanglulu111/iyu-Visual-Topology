# 叙事遮罩与显现协议
> “遮罩不是谎言的装饰，而是让真实在正确时刻显影的延迟装置。它保护 M 轴不被过早说破，也保护 SUR 层不被误当成原因。” —— 迷雾学派

## 一、遮罩的最终定义 叙事遮罩指的是：**用

SV1 的结构模板与

SUR 的可见材料，暂时遮住 M 轴的底层运算，使观众先进入一个可识别的类型表面，再在关键节点遭遇结构性反转。** 遮罩不创造 M 轴。它只控制 M 轴如何被看见。

| 层级 | 遮罩中的作用 |
| --- | --- |
| M0-M7A/M7B | 被遮罩延迟显影的结构骨架 |
| SUR1-SUR10 | 遮罩所使用的可见材料、身份、对象、空间与话语 |
| SUR-END | 遮罩最终留下的可见停点 |
| SV1/SV2 | 遮罩的工程展开方式、节拍与体量 |


## 二、SV1 结构遮罩

SV1 不是心理结构，而是受众熟悉的叙事入口。它可以采用三幕剧、英雄之旅、故事环、多线群像、非线性拼贴或伪纪录片形式，让受众暂时相信自己正在观看某种熟悉作品。

| SV1 模板 | 遮罩功能 | M 轴显影方式 |
| --- | --- | --- |
| 英雄之旅 | 提供“出发-试炼-回归”的熟悉路径 | 回归点被 M6/M7A/M7B 改写，不保证安宁。 |
| 经典三幕剧 | 提供建置、对抗、结局的稳定节拍 | 中点或高潮处暴露 M4/M6 的不可绕行。 |
| 哈蒙故事环 | 提供寻找与返回的循环结构 | “返回”不等于修复，可能只是缺失的回环。 |
| 非线性拼贴 | 延迟因果和责任归属 | 结尾回望时由 M7A 重排前文意义。 |
| 多线群像 | 扩大表层横截面 | 多个表层命运共同显示同一底层结构。 |


## 三、SUR 遮罩材料

SUR 层为遮罩提供表面材料，但每个材料都必须保持自己的权限：
- SUR1 提供类型节奏。
- SUR2 提供世界材质。
- SUR3 提供时空坐标。
- SUR4 提供社会外壳。
- SUR5 提供对象挂点。
- SUR6 提供空间容器。
- SUR7/SUR8/SUR9 提供人物可见呈现、年龄与社会身份。
- SUR10/SUR10X 提供开场信念语言与粘合强度。
- SUR-END 提供最后可见画面。 这些材料可以作为遮罩，但不能成为原因。例如：一张船票可以让故事看起来像逃亡片的麦高芬；它是否承载欲望，归 M3；它是否造成代价，归 M6；它最后意味着什么，归 M7A/M7B。

## 四、显影节点协议 遮罩必须在恰当节点被刺穿。刺穿不是突然解释理论，而是让已布置的表层材料暴露出它们无法继续遮蔽的结构后果。

| 节拍节点 | 可见动作 | 底层显影 |
| --- | --- | --- |
| 建置阶段 | 人物以 SUR10 语言自然解释世界 | M1 暂时不被明说，只以缺口姿态存在。 |
| 激励事件 | SUR5 对象、SUR6 空间或 SUR4 流程进入事件 | M2/M4 可能开始施压，但不由 SUR 解释。 |
| 中段反转 | 原本有效的社会身份或信念语言失效 | M3 的幻想开始失去遮蔽能力。 |
| 失去一切 | 对象、身份、空间或关系无法再提供保护 | M6 的代价逻辑逼近。 |
| 终端收束 | SUR-END 给出最后可见画面 | M7A 裁决意义，M7B 留下余痕。 |


## 五、生产自检清单
1. **遮罩是否过早解释 M 轴？** 如果角色在第一幕直接说出故事意义，遮罩失败。

2. **SUR 是否反向篡改 M 轴？** 如果对象、职业、年龄或空间被写成缺失原因，遮罩失败。

3. **SV 是否被误当成心理结构？** 如果“非线性”被直接解释为创伤本身，遮罩失败。

4. **SUR-END 是否抢走 M7A/M7B？** 如果最后画面已经写成判词或余痕说明，遮罩失败。

**边界声明**：遮罩只延迟与组织显影；不生成 M 轴原因，不改写 SUR 权限。
