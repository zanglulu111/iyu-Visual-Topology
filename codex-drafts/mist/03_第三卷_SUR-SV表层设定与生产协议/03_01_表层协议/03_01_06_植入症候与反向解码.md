# 植入症候与反向解码
> “一张图像可以召唤方向，但不能替理论判案。视觉种子只提供候选路径；最终参数仍必须接受 M/SUR/SV 三轴宪法的审查。” —— 迷雾学派

## 一、视觉种子的最终权限

视觉种子、创意种子、氛围片段、梦境意象或一句高概念，都可以作为生成入口。它们的功能是帮助系统找到一组可能的参数候选，而不是从一个画面直接锁死

M 轴。 最终权限如下：

| 输入 | 合法作用 | 不可越权 |
| --- | --- | --- |
| 图像 / 意象 | 提供色调、空间、对象、人物外观、可见收场候选 | 不直接判定 M1/M3/M4/M6/M7A/M7B |
| 高概念句 | 提供叙事方向、类型预感、社会外壳候选 | 不替代完整公式 |
| 情绪词 | 提供 SUR1/SUR2/SUR10 候选 | 不等于 M2 创伤或 M7A 裁决 |
| 最后一帧画面 | 提供 SUR-END 候选 | 不自动生成意义裁决或实在余痕 |


## 二、反向解码层级 反向解码必须按从表到里的顺序进行。越靠近

M 轴，越只能给候选，不得强行判定。

### 2.1 光影与类型层 提取

SUR1 / SUR2 候选：
- 镜头节奏、运动密度、剪辑速度。
- 色调、材质、文明模体、器物风味。
- 喜剧、黑色、动作、怪谈、文艺、邪典等类型语法。

### 2.2 空间与对象层 提取

SUR3 / SUR5 / SUR6 / SUR-END 候选：
- 时代与地理线索。
- 可被追逐、保存、打开、交换或护送的对象。
- 事件可能发生的可见空间。
- 若图像明显是“最后一帧”，只进入 SUR-END 候选。

### 2.3 社会与人物层 提取

SUR4 / SUR7 / SUR8 / SUR9 / SUR10 候选：
- 可见社会外壳：公司、教区、军队、学校、家族、平台、部落。
- 人物可见呈现、年龄阶段、社会身份或岗位。
- 人物开场可能使用的信念语言。

### 2.4 M 轴候选层 在完成表层候选后，才能提出 M0-M7A/M7B 候选。这里必须使用“可能”“倾向”“待校验”语言：
- 这个画面可能指向某类缺失姿态，但 M1 需由公式确认。
- 这个对象可能被 M3 欲望化，但对象本身仍属于 SUR5。
- 这个社会外壳可能承载某类 M4 阻断，但 SUR4 不等于 M4。
- 这个最后画面可能需要 M7A/M7B 解释，但 SUR-END 不替它解释。

## 三、候选映射表
| 视觉线索 | 首选候选层 | 可能延伸 | 禁止动作 |
| --- | --- | --- | --- |
| 雨夜高架桥、霓虹、门禁 | SUR2/SUR6/SUR4 | 可能提示冷硬、赛博、平台秩序 | 直接判定 M4 为技术大他者 |
| 破旧船票、登船队伍 | SUR5/SUR6/SUR-END | 可能提示逃亡、离岸、最后离开 | 直接写成“自由”或“救赎” |
| 年轻人穿工牌坐在空会议室 | SUR7/SUR8/SUR9/SUR6 | 可能提示办公室场域与开场话语 | 直接判定其 M1 是职业失败 |
| 烧焦的合照被压在档案袋下 | SUR5/SUR6 | 可能提示 M3 或 M7B 候选 | 直接裁定“与过去和解” |
| 雪地里只剩一只手套 | SUR-END/SUR5 | 可能需要 M7B 余痕解释 | 直接写出象征意义 |


## 四、闭环流程 Seed 输入
→ SUR 候选提取
→ SV 展开方式候选
→ M 轴候选生成
→ 三轴正交审查
→ 用户/系统确认
→ 进入动态缝合句
若任何候选违反以下规则，必须回退：
- SUR 候选含 M 轴理论词。
- SUR-END 候选含意义裁决。
- M 轴候选直接来自图像情绪而无结构论证。
- SV 候选被写成心理原因。

## 五、执行红线
1. **图像不是判词**：任何视觉线索都不能直接生成 M7A。

2. **对象不是欲望**：图像中的物只能先进入 SUR5，是否成为 M3 由公式决定。

3. **空间不是冲突**：图像中的地点只能先进入 SUR6，冲突来源另行判定。

4. **人物外观不是本质**：性别、年龄、职业只进入 SUR7/SUR8/SUR9。

**边界声明**：反向解码只生成候选，不替三轴宪法裁决参数。
