# SUR7-SUR10：人物呈现与开场话语
> “M 轴决定一个人为什么裂开；SUR7-SUR10 只决定这个裂开的人以什么外观、年龄、岗位和口头信念出现在世界里。” —— 迷雾学派

## 序言：人物外壳不是人物解释

SUR7-SUR10 是人物外壳层，而不是精神结构层。它们回答的是： 这个人物看起来如何？
处在什么年龄阶段？
以什么职业身份、社会身份或登记状态进入故事？
开场时抱着什么表层信念说服自己？
它们不回答： 这个人物为什么有缺口？那是 M1。
什么事件击穿他？那是 M2。
他把什么当成可追逐对象？那是 M3 与 SUR5 的接口。
他的结局被如何裁定？那是 M7A/M7B 与 SUR-END 的分工。

因此，SUR9 不能再写成一套职业决定论。职业身份只是人物在社会中的可识别外壳：岗位、证件、权限、工具、常用场域、可接触人群。它能让故事具体，但不能替故事解释人。

## 一、 SUR7-SUR8：选角参数与年龄阶段

SUR7 与 SUR8 只提供选角层和年龄层的表层约束。它们可以影响人物如何被看见、如何行动、如何被社会对待，但不能直接决定人物的精神结构。 当前 `data/engine_surface/SUR7/` 已重写为

**1 组 × 3 条，共 3 个选角呈现预设**；`data/engine_surface/SUR8/` 已重写为 **1 组 × 11 条，共 11 个年龄阶段预设**。这两个库都是轻量表层参数，不承担解释权。 合法句式： SUR7：人物呈现为女性/男性/非二元。
SUR8：人物处于幼年、少年、青年、中年、高龄或超龄状态。
这会影响体力、社会期待、亲密距离和公共空间中的可见性。
非法句式： 因为她是女性，所以她必然追求某种救赎。
因为他是老人，所以他天然代表虚无。
因为人物年轻，所以他的 M1 必须是某种创伤。
SUR7-SUR8 可以参与表层调度，但不能成为结构判词。

### 2.1 合法句式 身份预设：门诊医生。
可见接口：诊室、病历、处方、检查单、复诊系统、患者队列。
它只规定人物拥有怎样的社会岗位和接触权限；不解释人物为什么行动。

### 2.2 非法句式 医生天然是救赎者。
记者天然追求真理。
杀手天然没有灵魂。
流亡者天然代表悲剧。
这些句子都把职业身份写成了意义裁决。SUR9 不能写“天然”。它只能写“可见身份”和“行动接口”。

## 三、 SUR10 与

SUR10X：表层信念与认同强度 SUR10 仍然是表层信念库：人物开场时用什么话语解释世界。SUR10X 则描述人物与该信念的粘合程度。它们可以影响人物说话、选择理由、对公共秩序的态度，但不能替 M1 规定缺口，也不能替

M7A 规定故事意义。 合法句式： 人物带着冷淡怀疑进入故事。
人物对该信念处于 L3 反讽式粘合。
非法句式： 选择冷淡怀疑，所以故事必须走向退场。
选择人本主义，所以最后一定获得圆满。
信念是人物的开场语言，不是故事的最终判词。

## 四、 四层外壳的组合规则

SUR7-SUR10 的组合方式应该保持正交： SUR7/SUR8 =

可见选角与年龄阶段
SUR9 = 社会身份、职业岗位或登记状态
SUR10 = 表层信念内容
SUR10X = 信念粘合强度
示例：

| 组合 | 合法说明 |
| --- | --- |
| 中年 + 程序员 + 犬儒主义 + L3 | 一个中年程序员以犬儒口吻处理系统工作；他的核心缺口仍需由 M1 决定。 |
| 少年 + 教团子弟 + 原教旨主义 + L1 | 一个少年被教团身份和高粘合信念包围；故事意义不能由这个身份直接推出。 |
| 老年 + 清洁工 + 社会达尔文 + L2 | 一个年长清洁工用竞争话语解释日常；其行动方向仍由 M 轴闭合。 |


这些组合只为人物提供外壳、语言、场域和入口。它们可以让 M 轴落地，但不能反向决定 M 轴。

## 五、 质检红线
1. **禁止职业决定论**：不要写“因为他是律师，所以他必然……”。

2. **禁止职业人格论**：不要把职业直接等同于性格、创伤、信念或结局。

3. **禁止出身裁决**：王室、难民、黑帮子弟、克隆劳工都只是身份入口，不是故事判词。

**边界声明**：SUR7-SUR10 只提供人物外壳、社会岗位与信念语言；核心解释权仍归 M 轴。
