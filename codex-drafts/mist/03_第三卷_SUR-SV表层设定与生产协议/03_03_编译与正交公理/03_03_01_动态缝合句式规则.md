# 动态缝合句式规则
> “缝合句不是理论本身，而是理论进入生成器前的显影语法。它让表面排列成句，让工程形成秩序，并把 M 轴保留为不可被表面篡改的骨架。” —— 迷雾学派

## 序言：缝合句的最终权限

动态缝合句式是生成前的**预览编译器**。它将 M 轴、SUR 轴与 SV 轴压缩成一段自然语言预览，使 AI 在生成前知道：
- 这个故事的底层公式是什么。
- 它穿着什么表层外衣。
- 它按照什么工程结构展开。
- 最后可见画面由哪里提供。
- 意义裁决与余痕分别由哪里提供。 它不是第十四个参数，也不是隐藏的理论裁判。它只负责排列。

## 一、最终预览母句 在 [SUR3.时空坐标] 的 [SUR2.背景场域] 世界中，
运行于 [SUR4.社会形态] 之下。
一个 [SUR8.年龄阶段] 的 [SUR7.选角呈现] [SUR9.职业身份]，
带着 [SUR10X.信念裂度] 的 [SUR10.信念预设] 语言，
围绕 [SUR5.对象预设] 展开追寻、争夺或护送，
事件发生于 [SUR6.空间容器]，
形成这场 [SUR1.叙事动力] 故事。
最后可见收场由 [SUR-END.显性收场] 给出。 工程展开遵循 [SV1.结构模板] 与 [SV2.故事体量]。
底层推演遵循：

Story = M0 {[(M1↔M2↔M3)/M4]×M5} ⇒Act M6 → (M7A◇M7B) ↺ M1' 其中：
M7A 只负责象征裁决。
M7B 只负责实在余痕。
SUR-END 只负责最后可见画面。
这段母句的关键不是华丽，而是**权限清晰**。它让 SUR 和 SV 进入句子，却不让它们解释 M 轴。

## 二、语义自愈协议

SUR 参数是辅助预设，不是强制义务。留空意味着把该表面维度交还给 AI 的场域推理，而不是让故事缺损。

| 留空项 | 自愈方式 |
| --- | --- |
| SUR7 / SUR8 留空 | 不强调选角呈现或年龄阶段，以更中性的可见人物进入故事。 |
| SUR9 留空 | 不预设职业，由场域、社会形态与行动需求自然生成社会接口。 |
| SUR10 留空 | 不预设开场信念语言，由剧情压力逐步显出人物说话方式。 |
| SUR10X 留空 | 不预设信念粘合强度，人物与语言的距离由事件自然显示。 |
| SUR5 留空 | 不强行设置对象锚点，故事对象由 M3、M5 与场域共同显影。 |
| SUR6 留空 | 不指定局部空间，关键事件根据 SUR2/SUR3/SUR4 自行落点。 |
| SUR-END 留空 | 不预设最后画面，由 M6/M7A/M7B 的闭合需求生成可见收场。 |


## 三、阻断逻辑：只阻断越权，不阻断风格 本章不使用“表面强度 vs 底层强度”的阻断。系统只阻断一种错误：**表层参数反向篡改

M 轴**。

| 阻断类型 | 触发条件 | 正确处理 |
| --- | --- | --- |
| SUR5 越权 | 对象词条写成“自由、救赎、真相、复仇” | 改回可见对象；意义交给 M3/M7A。 |
| SUR6 越权 | 空间词条预写冲突、代价或结局 | 改为空间容器；事件交给 M5/M6。 |
| SUR9 越权 | 职业身份被写成人物本质 | 改为社会岗位；缺失交给 M1。 |
| SUR10 越权 | 信念语言解释主体为何存在 | 改为开场话语；缺失与欲望交给 M1/M3。 |
| SUR-END 越权 | 显性收场写出意义裁决或余痕后效 | 拆分：画面留在 SUR-END，判词入 M7A，余味入 M7B。 |
| SV 越权 | 结构模板被写成心理结构或理论原因 | 改为显影顺序；原因交给 M 轴。 |


## 四、编译检查清单

每次生成预览句前，系统必须确认：
- 是否把 SUR4 写成 M4 的实体化身。
- 是否把 SUR5 写成 M3 的欲望原因。
- 是否把 SUR6 写成 M2、M4 或 M6 的事件来源。
- 是否把 SUR7/SUR8 写成人物本质。
- 是否把 SUR9 写成 M1 缺失。
- 是否把 SUR10 写成哲学结论。
- 是否把 SUR-END 写成 M7A/M7B。

若任一项成立，缝合句不得交付生成端。

**边界声明**：缝合句只编译参数，不创造参数；只排列现象，不裁决意义。
