> **适用范围**: SUR1 ~ SUR11 全部表层词库  
> **最后更新**: 2026-04-14  
> **状态**: ✅ SUR1/SUR2/SUR4 已完成改造 | 🔴 SUR5~SUR11 待改造

---

## 一、架构原则：骨-皮正交性

SUR（Surface / 皮）层与 M（Core / 骨）层之间必须保持**绝对正交**：

| 层级 | 职责 | 禁止内容 |
|------|------|----------|
| **M 层** (M0-M7) | 精神拓扑、驱力回路、动能物理 | 不得预设具体场景/职业/时代 |
| **SUR 层** (SUR1-11) | 外部世界设定、环境参数 | **不得使用 M 层术语、不得预判 M 层介入方式** |

### 🔴 绝对禁止出现在 SUR 词条中的内容

- `M0` ~ `M7` 任何模块代号
- `大他者`、`主体`、`能指`、`所指`、`换喻`、`隐喻` 等拉康术语
- `【换喻】`、`【隐喻】` 等修辞学前缀标记
- `M4（大他者阻断）表现为……` 等锚定语句
- 任何形式的 `| 锚定 ($): Mx ...` 标注

## 二、数据结构（TypeScript Schema）

每个词条遵循 `LibraryCategoryDef` 接口：

```typescript
// ========== 组级（Group）==========
{
  id: "era_mythic",                    // 唯一标识符，snake_case
  name: "01. 起源与神话",               // 中文组名（带序号）
  nameEn: "Origins & Mythic",          // 英文组名
  desc: "文明的童年。……",              // 组级描述（纯 SUR 层语言，≤50字）
  defEn: "Childhood of civilization…", // 英文组级描述
  items: [...]                         // 词条数组
}

// ========== 词条级（Item）==========
{
  id: "primordial_chaos",              // 唯一标识符，snake_case
  name: "原初混沌",                     // 中文名
  nameEn: "Primordial Chaos",          // 英文名
  def: "……",                           // 定义/描写（见第三节）
  defEn: "……",                         // 英文定义
  core: "……",                          // 核心逻辑（见第四节）
  coreEn: "……",                        // 英文核心逻辑
  reference: "……",                     // 参考作品（见第五节）
  referenceEn: "……",                   // 英文参考作品
}
```

### ⚠️ 语法注意

- 所有字符串使用**双引号** `""`
- 字符串内部的双引号**必须转义**：`\"`
- 例：`def: "基于\"不洁\"设定的阶级固化。"`

## 三、`def` 字段：定义/描写

### 3.1 功能定位

`def` 是该词条的**场景画面感描述**——读完之后，读者能立即产生一个具体的视觉/氛围想象。

### 3.2 书写规则

| 规则 | 说明 |
|------|------|
| **长度** | 25~50 字（中文），1~2 句话 |
| **语感** | 短促、有力、画面感强。像电影概念海报的 tagline |
| **禁止** | 不得出现 M 层术语、不得做理论分析 |
| **时态** | 现在时，描述性（非叙事性） |

### 3.3 各 SUR 层的 def 定语前缀（UI 显示）

不同 SUR 层的 `def` 字段在 UI 中会自动添加对应的**定语前缀**，用于帮助用户理解该字段在当前词库中的语义角色：

| SUR 层 | blockId | UI 前缀 | 英文前缀 | 描写对象 |
|--------|---------|---------|----------|----------|
| SUR1 | `skin_genre` | 定义: | Def: | 这是什么类型/风格 |
| SUR2 | `skin_era` | 时空背景: | Background: | 这个时代的环境氛围 |
| SUR4 | `skin_society` | 社会描写: | Social: | 这种社会制度的状态 |
| SUR5 | `skin_everything` | *(待定)* | | 欲望对象的描写 |
| SUR6 | `skin_location` | *(待定)* | | 空间场景的描写 |
| SUR7 | `skin_gender` | *(待定)* | | 性别设定的描写 |
| SUR9 | `skin_profession` | *(待定)* | | 职业身份的描写 |
| SUR10 | `skin_ideology` | *(待定)* | | 信念/哲学立场 |
| SUR11 | `skin_ending` | *(待定)* | | 结局形态的描写 |

### 3.4 示例

```
✅ "朕即国家。君权神授，皇帝的身体就是法律，不可质疑的权威。"
✅ "天地未分。物理定律尚未固化，物质与意志直接碰撞。"
✅ "吴宇森式双枪、慢动作、鲜血与西装、浪漫化的杀戮。"

🔴 "M4 表现为不可僭越的国家机器。"          ← 违反正交性
🔴 "主体在此社会中被大他者阻断。"            ← 使用了 M 层术语
```

## 四、`core` 字段：核心逻辑

### 4.1 功能定位

`core` 是该词条的**内在张力结构**——描述这个设定中蕴含的、可以被叙事利用的对立矛盾。

### 4.2 书写规则

| 规则 | 说明 |
|------|------|
| **长度** | 30~60 字（中文），1~2 句话 |
| **结构** | 推荐使用 `X vs Y` 对立张力格式，后跟一句展开 |
| **语感** | 锐利、形式化，像一个数学公式的文学表达 |
| **禁止** | `【换喻】`、`【隐喻】` 标记；所有 M 层术语 |
| **用语** | 纯 SUR 层——用环境/制度/物理/社会层面的语言 |

### 4.3 UI 前缀

`core` 字段在所有 SUR 层中统一使用 **"核心逻辑:"** / **"Core:"** 前缀。

> 唯一的例外：SUR2（背景场域）当前使用 **"核心张力:"** / **"Core Tension:"**，后续可能统一为"核心逻辑"。

### 4.4 示例

```
✅ "皇权的任性 vs 臣民的恐惧。一人之躯等同于法典，所有人的生死悬于御座一念之间。"
✅ "优雅的秩序信条 vs 失控的杀戮泥沼。暴力被仪式化为美学，义气与背叛共生于同一套规矩。"
✅ "无序的自然伟力 vs 微弱秩序的萌芽。混沌与形态之间的零和博弈。"

🔴 "【换喻】皇权的任性 vs 臣民的恐惧"      ← 带有修辞学前缀
🔴 "大他者的凝视 vs 主体的逃逸"              ← 使用了 M 层术语
🔴 "M4 律法坏死 (Law_Necrosis)"             ← 直接锚定 M 层模块
```

## 五、`reference` 字段：参考作品

### 5.1 格式标准

统一为**干净的引用格式**：

```
《作品中文名》(年份, 导演/创作者)
```

多个作品之间用 ` / ` 分隔。

### 5.2 规则

| 规则 | 说明 |
|------|------|
| **数量** | 2 部作品为标准（最多 3 部） |
| **长度** | 每条 reference ≤ 60 字 |
| **禁止** | 不写画面描述、不写剧情、不写角色行为 |
| **优先级** | 优先选择最具代表性、辨识度最高的作品 |
| **格式** | 剧集标注"剧集"、游戏标注"游戏"、小说标注作者+小说 |

### 5.3 示例

```
✅ "《末代皇帝》(1987, 贝纳尔多·贝托鲁奇) / 《疯狂的麦克斯4》(2015, 乔治·米勒)"
✅ "《黑镜》(2011-, 剧集) / 《奥维尔号》(2017-, 剧集)"
✅ "《我们》(扎米亚京, 小说) / 《千钧一发》(1997, 安德鲁·尼科尔)"
✅ "《辐射》(游戏系列) / 《沙丘》(2021, 丹尼斯·维伦纽瓦)"

🔴 "《末代皇帝》拥太和殿生杀大权、圣体即国法的孤绝真龙" ← 写了画面描述
🔴 "《疯狂的麦克斯4》垄断水源将臣民视作血袋的不死老乔"  ← 写了剧情
```

### 5.4 英文 reference 格式

```
"The Last Emperor" (1987, Bernardo Bertolucci) / "Mad Max: Fury Road" (2015, George Miller)
```

## 六、`desc` 字段：组级描述

### 6.1 功能定位

组级的 `desc` 是对整个分类的**一句话概括**。

### 6.2 规则

| 规则 | 说明 |
|------|------|
| **长度** | ≤ 50 字 |
| **禁止** | 不得出现 `M4（大他者阻断）表现为……` 等 M 层锚定 |
| **语感** | 简洁、概括性、画面感 |

```
✅ "权力高度集中，个人服从集体，恐惧作为统治工具。"
✅ "文明的童年。逻辑未立，人神共居，生存法则极其原始且带有神圣的残酷。"

🔴 "M4（大他者阻断）表现为不可僭越的国家机器与物理剥权。" ← 锚定了 M 层
```
