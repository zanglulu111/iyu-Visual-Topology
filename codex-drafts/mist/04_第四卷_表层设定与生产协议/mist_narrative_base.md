# 4_02_1_1 叙事底色层 (The Narrative Base)

> “底色不是背景，而是整个叙事场域的‘第一推动力’。它决定了光线如何折射，以及欲望如何在这片场域中被阻滞。”

在本项目中，叙事底色由 **[类型基因 (Genre Gene)]** 与 **[动画基因 (Animation Gene)]** 共同构成。

---

## 1. 类型基因 (Genre Gene / S0)：公式权重的自动化校准

类型基因（S0）不再被视为一种简单的视觉风格分类，它是**“叙事拓扑指令的第一优先级”**。它决定了底层公式 `Story = M0 { [ (M1 -> M2 -> M3) / M4 ] * M5 }` 中各个变量的**默认权重 (Weights)**。

### 1.1 类型对权重的自动化锁定
*   **[Noir / 黑色电影]**：
    *   **权重锁定**：$M4$ (大他者) >>> $M1$ (主体)。
    *   **逻辑**：世界（M4）被预设为恶意的、无法被看透的反派。主体的抗争（M5）往往只会确认其自身缺失（M1）的深度。
*   **[Wuxia / 武侠江湖]**：
    *   **权重锁定**：$M5$ (驱力) > $M2$ (实在冲突)。
    *   **逻辑**：强调个体的行动力（M5）。冲突不来自外界的不可知论，而来自具体的“恩怨”作为 $M2$ 的爆发。
*   **[Sci-Fi / 科幻]**：
    *   **权重锁定**：$S3$ (社会形态) $\approx$ $M4$ (重力场)。
    *   **逻辑**：设定本身即是压迫。大他者（M4）通常具象化为某种非人的逻辑、算法或系统（S3）。

---

## 2. 动画基因 (Animation Gene / S0-Anim)：象征界的审美层级

动画基因定义了**“象征界（Symbolic）的稳固程度”**。作为本叙事引擎的视觉载体，它决定了主体如何感知这个“虚假但美”的现实。

### 2.1 审美层级的叙事降维
*   **[写实动画 / Grounded Animation]**：
    *   **功能**：强化 $M2$ (实在冲突) 的触觉质感。每一个“污点”或“刺”都必须在极其写实的背景中产生极强的痛感。
*   **[极简动画 / Minimalist]**：
    *   **功能**：放大 $M1$ (缺失) 的留白效应。背景的极度精简，反衬出主体欲望对象的稀缺与珍贵。
*   **[怪诞/超现实动画 / Surrealist]**：
    *   **功能**：模糊象征界与实在界的界限。$M2$ 的冲突可能直接改变皮相的物理法则，使“刺”本身成为背景。

---

## 3. 参数交互逻辑 (Interaction Logic)

**本片以 [类型基因] / [动画基因] 作为叙事底色。**

当这两个参数被选定时，生成器应自动根据以下矩阵进行预设：

| 参数组合 | 审美效果 | 叙事动力 |
2: | :--- | :--- | :--- |
3: | **[Noir] + [写实]** | 极度压抑的、可触知的阴影 | 绝望的调查，真相（M3）是唯一的解药却有毒 |
4: | **[Cyberpunk] + [绚烂]** | **面具的极致圆满** (Neon Mask) | 在极度华丽的都市碎片（S2）中，寻找肉身的残片（M1） |
5: | **[Gothic] + [黑暗]** | 腐朽的精美 | 循环的诅咒作为 $M4$，主体在华丽废墟中起舞 |

---

## 4. 终极转换指令 (Final Command)

1.  **拒绝扁平化**：当用户选择 [类型] 时，不要只给出一套风格化的形容词，要给出一套**“受阻的路径”**。
2.  **审美欺骗性**：动画基因必须确保视觉上的**“完整且美”**，直到那一根“刺”出现。
