# 旧第五卷归档说明

本目录保存旧“第五卷：主体档案与词条”的材料。

该卷已退出 active theory。原因是：三、四卷已经承担了引擎参数的概念定义与本体论定位；若第五卷继续以辞典形式复述拉康、黑格尔、齐泽克概念，会使理论结构重复、臃肿，并削弱 M0-M7 与 SUR/SV 自身的解释权。

后续处理原则：

1. **可吸收者并入三卷**：锚点、污点、图像裂口、触觉视觉等应进入卷一；对象 a、余痕、驱力、回溯性等应在卷二对应位点内说明；转译协议、命名协议、反庸俗与本体论卫生学应进入卷三。
2. **无生产功能者可删除**：若某词条只是旧模型讨论产物或哲学概念复述，没有原创生产功能，可以列入删除清单。
3. **历史价值者保留归档**：若某词条记录了迷雾学派概念形成过程，可保留在归档中，但不再参与 active theory。
