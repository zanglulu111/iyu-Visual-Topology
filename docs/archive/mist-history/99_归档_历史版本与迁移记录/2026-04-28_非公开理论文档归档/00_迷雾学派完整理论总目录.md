# 迷雾学派最终理论包总目录

> “一个理论真正完成时，不是它拥有更多卷，而是它终于知道哪些话不必再说。”

> [!IMPORTANT]
> 本目录是 `codex-drafts/mist` 的当前 active theory 入口。最终理论包采用**总纲 + 三卷 + 归档**结构。旧“第五卷：主体档案与词条”已退出 active theory，并移入 `99_归档_历史版本与迁移记录/05_旧第五卷_概念词典占位稿`。若旧卷名、旧文件名或旧词条与本文冲突，以本文为准。

## 0. 最终结构

迷雾学派最终理论包由三个正卷构成：

```text
00 总纲与宪法
定义完整理论入口、核心公式、迁移规范与归档边界。

卷一：迷雾学派与爱欲结构拓扑学
定义学派本体、爱欲结构发生器、爱欲视觉拓扑学与图像裂缝理论。

卷二：核心叙事引擎 M0-M7
定义 M0-M7、M7A/M7B 双结项、回路、势能、公式与引擎操作。

卷三：SUR/SV 表层设定与生产协议
定义 SUR 现象显现、SV 工程展开、正交公理、词库生产与提示词编译。

99 归档
保存历史版本、旧第五卷、迁移记录、临时报告和不再 active 的旧材料。
```

最终生产顺序为：

```text
卷一提供本体论理由。
卷二提供叙事生成骨架。
卷三提供表层显现与工程展开。
```

旧“概念词典”不再作为独立正卷。所有必要概念必须被吸收到以上三卷中：缺失进入卷一与 M1，对象 a 进入 M3 与 SUR5 边界，余痕进入 M7B，锚点/污点/图像裂口进入爱欲视觉拓扑学，转译协议/命名协议/反庸俗进入卷三生产协议。

## 4. 什么属于 active theory

以下材料留在最终理论包：

1. **卷一材料**：定义学派本体论、爱欲结构发生器、爱欲视觉拓扑学、图像裂缝、锚点、污点与触觉视觉的材料。
2. **卷二材料**：定义 M0-M7 公式、位点、回路、势能、M7A/M7B 双结项的材料。
3. **卷三材料**：定义 SUR/SV 正交生产、表层设定、空间容器、对象预设、社会身份、计算器、词库生产和 prompt 编译的材料。

active theory 的判断标准是：

```text
它是否直接回答“迷雾学派如何把缺失结构生产为作品”。
```

## 5. 什么应放到归档或外部目录

以下材料不应留在 active theory 入口：

1. **旧第五卷概念词典占位稿**：若只是复述拉康、黑格尔、齐泽克概念，而不能提供新的生产功能，应归档。
2. **只记录旧命名的迁移草稿**：如旧 M8、旧 M7、旧 SUR11 的未清洗版本。
3. **只服务某次产品实现的临时报告**：例如一次 UI 同步清单、一次词库数量审计、一次 prompt 热修记录。
4. **不含理论归属的视觉实验**：单张海报、图像提示词、风格样张、商业素材、纯案例输出。
5. **与迷雾学派无关的外部方法论**：若不能被三卷制吸收，应移出 `mist` 或放入 `99_归档_历史版本与迁移记录`。

归档不是删除。归档的意义是防止旧材料继续拥有 active theory 的解释权。若确认某些归档材料只是与 Claude Code 或其他模型的临时讨论结果，且没有历史保留价值，下一步可以再做删除清单。
