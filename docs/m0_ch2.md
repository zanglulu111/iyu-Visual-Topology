## 二、 哲学史坐标与理论根基 (Theoretical Foundations)

### 2.1 临床拓扑：结构的本质即"折叠方式"

迷雾学派将临床结构的本质，还原为符号平面（大他者）受压后的四种折叠形态：
*   **折叠 (Fold/Neurosis)**：向内弯曲，产生重叠的阴影（压抑）。
*   **翻转 (Flip/Perversion)**：将正反面混淆，作为工具去刺穿平面（恋物）。
*   **撕裂 (Rupture/Psychosis)**：平面彻底失效，真实界的岩浆直接喷涌（排除/斥逐）。
*   **合拢 (Shell/Autism)**：平面尚未展开或拒绝展开。主体把自己封装在一个物理性的"硬壳"内，阻止符号化（拒绝）。

### 2.2 齐泽克的意识形态滤镜 (Ideological Screen)

齐泽克认为，意识形态不仅是洗脑，而是**一种让现实变得可以忍受的"幻象架构"**。
*   M0 同样承担了这种功能。它告诉主体："你之所以痛苦，是因为[体制/仇人/某个特定的物]。"它为主体提供了一个指向外部的攻击点，从而掩盖了主体内部坍塌的 M1（缺失）。

### 2.3 M0 作为"静态场"的正交性承诺

v3.0 的核心架构升级在于明确 M0 的**本体论静态性**：

*   **M0 是地形，不是天气**：M0 描述的是主角精神空间的"地质结构"——山脉、裂谷、熔岩层。而 M2（遭遇）、M5（驱力）、M6（代价）描述的是在这个地形上发生的动态事件。**M0 词条严禁包含叙事事件、角色行为或情节预设。**
*   **场域描写风格 (Field Description Style)**：v3.0 要求所有 M0 词条以**"主角"为锚点，描述主体附近的现实弯曲方式**。不说"角色会如何行动"，而说"在角色所站的位置上，现实以何种方式发生扭曲"。
*   **与 M4 的正交边界**：M0 定义的是主体与大他者的**先验关系模式**，M4 定义的是大他者在具体叙事中的**阻断地形**。两者的区别在于：M0 是"这个人从出生就携带的引力场"，M4 是"这个人此刻面对的具体障碍"。
