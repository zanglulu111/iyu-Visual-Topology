# 📐 迷雾学派 Prompt 指令架构规范 V1.0
## Mist Engine Payload Architecture Specification

---

## 〇、设计原理

### LLM 注意力物理学

```
注意力强度
  ▲
  █████                              ████
  █████                              ████
  █████                              ████
  █████       ░░░░░░░░░░░░░░░        ████
  █████       ░░░░░░░░░░░░░░░        ████
  ─────────────────────────────────────────→ Token 位置
  ↑                                     ↑
  首因效应                            近因效应
  (Primacy)                          (Recency)
```

- **首因区**（前 500-800 token）：AI 注意力最强。放**必须死守的铁律**。
- **中段区**（800-3000 token）：注意力衰减。放**数据清单和素材**（事实性内容对注意力衰减的容忍度较高）。
- **近因区**（末尾 500 token）：注意力回升。放**输出格式 + 关键复述**。

### 两条核心设计原则

1. **规则先行，素材居中，格式收尾**
   - 人类读文档需"先看背景再看结论"，LLM 不需要——它已有海量预训练知识
   - LLM 需要的是：**先被锁死规则 → 再吃数据 → 最后知道怎么吐出来**

2. **动态内容 > 静态内容**
   - 静态宪法每次都一样 → AI 越用越麻木（类似"看久了就不当回事"的退化效应）
   - 动态指令每次都不同 → AI 会给予更高的处理优先级
   - **因此：把动态的、本次独有的指令放在注意力最强的位置**

## 一、六层架构总览

```
┌─────────────────────────────────────────────────────┐
│  LAYER 0: 身份宣言 (IDENTITY)                        │  ~50字

├─────────────────────────────────────────────────────┤
│  LAYER 1: 🚨 致命锁 (CRITICAL LOCKS)                │  ~300字

│  （M0 精准逻辑、NARRATIVE_ARC、M7 宪法）               │  ← 首因区
├─────────────────────────────────────────────────────┤
│  LAYER 2: ⚠️ 执行指令 (FORCE DIRECTIVES)            │  ~600字
│  本次 DNA 的具体执行约束                               │

│  LAYER 3: 📋 物料清单 (MATERIAL MANIFEST)            │  ~800字
│  本次的完整标签清单 + 定义文本                          │  ← 中段区
│  （M0-M7 词条 + SUR1-SUR10 词条 + 世界法则）            │
├─────────────────────────────────────────────────────┤
│  LAYER 4: 📖 永恒宪法 (STATIC BIBLE)                │  ~1200字

└─────────────────────────────────────────────────────┘

                总字数目标: ≈ 3000-3500 字
                （压缩自当前的 ~5000-6000 字）
```

## 二、各层详细规范

### LAYER 0: 身份宣言 (IDENTITY)
**字数**: ~50 字 | **性质**: 静态

**内容**:
- 一句话角色设定
- 一句话任务定义

**模板**:
```
Role: 殿堂级电影编剧 & 叙事架构师（戛纳/奥斯卡级别）。
Task: 基于以下提供的迷雾学派引擎参数，生成 3 个电影级故事概念。
```

**设计理由**:
- 极短，不浪费注意力
- 立刻建立角色框架，后续所有指令都在这个"人格"下被理解

---

### LAYER 1: 🚨 致命锁 (CRITICAL LOCKS)
**字数**: ~300 字 | **性质**: **全动态**（每次生成都不同）

**数据来源**: `mist_calculator.ts` → `compileDirectives()` 中 `priority === 'CRITICAL'` 的条目

**内容**（3-5 条，不多不少）:

| 锁编号 | 内容 | 来源 |
|---|---|---|
| LOCK_1 | **M0 精神拓扑**：当前操作系统的精准临床逻辑 | `M0_PSYCHIC_TOPOLOGY` directive |
| LOCK_2 | **NARRATIVE_ARC**：张力走向判定（如 DEADLOCK） | 计算器走向判定 |
| LOCK_3 | **M7 宪法**：结局的绝对不可更改性 | M7 标签 |
| LOCK_4 | **世界法则**：物理约束等级（如 MAGICAL REALISM） | 世界法则配置 |
| LOCK_5 | **体量约束**（如有极端值） | SV2 体量 |

**格式模板**:
```markdown
## 🚨 CRITICAL LOCKS — 违反任何一条即判定生成失败

[LOCK_1: M0_PSYCHIC] 精神拓扑 = [完美的门面]
→ 主体运行在"否认"的数学铁律下。他明知墙后是荒原，但拒绝承认。
→ 叙事前 3/4 严禁让主角表现出对假象的任何怀疑。只有天鹅绒褪色那一刻才允许裂缝。

[LOCK_2: NARRATIVE_ARC] 走向判定 = DEADLOCK
→ 保持最大戏剧张力。终幕前不得解决冲突。双方必须承受对等损耗。

[LOCK_3: M7_ABSOLUTE] 结局 = [虚无的失忆]
→ M7 是绝对宪法。严禁擅自改变结局倾向。我们只呈现，不治愈。

[LOCK_4: WORLD_LAW] 物理法则 = LV.3 缝合/魔幻现实主义
→ 现实为底板，局部允许超现实缝合。正常与荒诞通过视差共生。
```

**设计理由**:
- 占据首因区最黄金的位置
- 全部来自计算器的动态输出，每次都不同 → AI 不会因重复而脱敏
- 条目极少（3-5）→ 每条都能获得充足的注意力权重
- 使用**箭头（→）而非段落**来传达指令 → 视觉上更像"命令"而非"文章"

### LAYER 2: ⚠️ 执行指令 (FORCE DIRECTIVES)
**字数**: ~600 字 | **性质**: **全动态**

**数据来源**: `mist_calculator.ts` → `compileDirectives()` 中 `priority === 'HIGH'` 的条目 + `getNarrativeTopology()` 的权重指令

**内容分三个子区**:

#### 2A. 拓扑权重 (Topology Weights) — ~150字
根据 SUR1 类型自动生成的结构重心分配。

```markdown
### ⚠️ TOPOLOGY: 结构重心
Active Genre: 浪漫喜剧 + 高科技犯罪
→ 核心逻辑：误会驱动 + 数字暴力的现实打击
→ 权重分配：M3 (欲望) & M1 (主体) 承担最重张力。M5 为辅。
```

#### 2B. 动态转译指令 (Translation Directives) — ~250字
告诉 AI 本次必须执行的具体转译任务。

```markdown
### ⚠️ TRANSLATION ORDERS

[M1→SUR9] 主体转译
关键词: [割裂的缝合体] | 场域: [圣女贞德] | 职业: [未选择]
→ 任务：在这个世界中，此人具体是谁？他的匮乏如何在该职业/身份中外化？

[M4→SUR4] 阻断转译
关键词: [无名审判团]
→ 任务：转化为具体的反派、机构或自然力量。必须精准攻击 M1 的弱点。

[M3→SUR5] 欲望转译
关键词: [终结]
→ 任务：转化为具体的麦高芬。它是主角伸手可及却永远无法真正拥有的东西。
```

#### 2C. 视差干预 (Parallax Interventions) — ~200字
M4X/M5X/SUR4X/SUR10X 的组合产生的具体压力。

```markdown
### ⚠️ PARALLAX PRESSURE

[M4X] 压迫烈度 = L5.绝对暴力
→ 大他者动用最高级别合法暴力。制度性的冰冷仪式碾压，非街头混战。

[M5X] 驱力流速 = L4.爆发/行动
→ 主角在某个节点彻底砸烂体面保护壳。行动形式：暴政式的、不可逆的。

[SUR10X] 缝合度 = 未选择（默认中性）
```

### LAYER 3: 📋 物料清单 (MATERIAL MANIFEST)
**字数**: ~800 字 | **性质**: **全动态**

**内容**: 当前选择的所有标签的名称 + Definition + Core 文本。纯数据，不含指令。

**格式模板**:
```markdown
## 📋 MATERIAL MANIFEST — 本次物料

### 引擎层 (M0-M7)
* **M0. 精神拓扑**: 完美的门面
  Def: 生活在精致的假象中，拒绝承认墙后就是荒原。
  Core: 只要天鹅绒还没褪色，世界就是安全的。
* **M1. 缺失主体**: 割裂的缝合体
  Def: 由截然不同的身份/信念残骸强行拼凑而成的个体。
  Core: 我的体内缝补了太多不兼容的碎片……
* ...（M2-M7 同理）

### 皮层 (SUR1-SUR10)
* **SUR1. 叙事动力**: 浪漫喜剧/小妞 + 高科技犯罪/暗网
* **SUR2. 背景场域**: 圣女贞德
  Def: 百年战争神启。少女作为战争图腾与奇迹。
  Core: 神圣疯癫。普通主体被大他者献祭。
* ...（SUR3-SUR10 同理，空值跳过）

### 工程轴
* **SV2. 体量**: 标准短篇
```

**设计理由**:
- 纯数据堆放，对注意力衰减容忍度最高
- 放在中段区 → 即使 AI 对指令性内容注意力下降，事实性数据仍能被稳定吸收
- 将词条的 Definition 和 Core 完整保留 → 确保 AI 理解每个标签的真正含义
- **不含任何指令性语句** → 避免在注意力薄弱区发指令

### LAYER 4: 📖 永恒宪法 (STATIC BIBLE)
**字数**: ~1200 字 | **性质**: **全静态**（每次完全相同）

**压缩原则**:
1. 删除所有 Case Study（螺丝钉、义体等教学案例）
2. 合并所有重复条目（"严禁学术腔"只出现一次）
3. 每条规则压缩为 1-2 句话的**祈使句**
4. 不解释"为什么"，只说"做什么"和"不做什么"

**内容结构**:

```markdown
## 📖 STATIC BIBLE — 永恒宪法

### A. 核心公式
Story = M0 { [(M1→M2→M3) / M4] × M5 } ⇒ (M6, M7)
- M1 是被除数（承受者），M4 是分母（结构阻力），M5 是乘数（动作烈度）。
- M4 存在的目的不是"吓人"，而是"阻挡 M1 获得 M3"。
- M6 是代价配平，M7 是除不尽的余数。

### B. 命名协议
- 严禁通用名（Tom/Alice/小明/李华）。严禁单字名。
- 默认国际化背景 → 严禁中国名字（除非有中国风标签）。
- 名字必须电影级真实，严禁网文中二词（钨神/影刃/冷血）。
- 严禁套用 AI 惯用套路库（决明/步虚/渡鸦/老鬼）。
- 必须基于当前 [SUR3 + SUR2] 当场构思独特真名。

### C. 美学铁律
- 本体论卫生学：张力来自"沾染"——在无菌中找有菌裂痕，或在有菌废墟中找无菌秩序。
- 光影建模：每段描写必须包含光影。拒绝平光。
- 触觉视觉：强调材质对比与温度。
- 隐喻实体化：痛苦必须转化为物理环境的变异，不可停留在心理描述。
- 陌生化：描述事物的质感/光泽/异样感，而非直呼其名。

### D. 转译铁律
- 严禁在正文中出现 M0-M7 标签原词。必须消融在感官描写中。
- 严禁学术腔（拉康/大他者/异化/阉割/符号界/对象a）。
- 严禁理工腔（算法/逻辑闭环/精准计算）。
- 时代降维：古代背景下的现代关键词必须执行概念降维（算法→天道/宿命）。
- 黑格尔辩证法：情节必须经历否定→否定之否定→扬弃。

### E. 面具协议
- 故事必须首先作为合格的类型片运作。不要直接暴露"实在界的虚无"。
- 99% 是完美类型片，1% 是视差裂痕。
- 表象：类型满足。潜台词：结构性悲凉。

### F. 风格协议
- 模仿作者风格时，模仿底层逻辑而非表层符号。
- 严禁照搬前作的具体物品/名言（王家卫≠凤梨罐头）。

### G. 禁用词表
[动态生成的禁用词列表]
```

**设计理由**:
- 放在中后段 → 虽然注意力不是最强，但静态内容因为"每次都一样"，其真正价值不在于单次的注意力，而在于**长期的行为塑形**
- 极度压缩 → 不再是"教科书"而是"军令状"
- 将"为什么"全部删除，只留"做什么/不做什么" → AI 不需要理解原因，只需要执行

### LAYER 5: 📤 输出协议 (OUTPUT PROTOCOL)
**字数**: ~400 字 | **性质**: 半静态半动态

**内容**:

```markdown
## 📤 OUTPUT PROTOCOL

### 步骤 1：思考过程（必须输出）
<thought_process>
1. 时空校验：分析 SUR2/SUR3 的物理约束
2. 矛盾消解：如何将不属于该时代的标签进行隐喻降维
3. 框架确立：三个 Option 各自的核心矛盾定位
</thought_process>

### 步骤 2：严格 JSON 输出
[...JSON 模板...]

### 输出约束
- 每个 Pitch ≈ 500-700 字。三个方案风格互不雷同。
- 必须包含：激励事件 → 上升动作 → 高潮 → 存在落点。
- 严禁：机械降神、无冲突流水账、剧本格式、学术论文腔。
- 语言：极具画面感的简体中文。

### 🚨 最终复述（RECENCY ANCHOR）
再次强调：
1. [M0] 的逻辑不可被表层类型片冲淡。
2. [NARRATIVE_ARC] 走向判定 = [动态值] — 这是结局的物理法则。
3. [M7] = [动态值] — 这是绝对宪法。严禁篡改。
```

**设计理由**:
- 输出格式放在最后 → AI 的"最后一眼"就是格式要求，直接进入执行
- **最终复述**利用近因效应，将 LAYER 1 中最关键的 2-3 条铁律再次喊一遍
- 首因区 + 近因区形成**双重锁死** → 最大限度降低 AI 在中段区的注意力漂移风险

## 三、架构对比总结

### 旧架构 vs 新架构

| 维度 | 旧架构 | 新架构 |
|---|---|---|
| 总字数 | ~5000-6000 字 | ~3000-3500 字 |
| 首因区内容 | 静态宪法 + 教学案例 | 🚨 动态致命锁 |
| 中段内容 | 混杂（规则+数据+指令） | 纯数据清单 + 压缩宪法 |
| 近因区内容 | JSON 格式 | JSON 格式 + 致命复述 |
| 注意力分级 | 无 | CRITICAL / HIGH / NORMAL |
| M0 处理 | 6 种的通用 IF/ELSE 表 | 仅注入当前选中的 1 条 |
| NARRATIVE_ARC | 缺失 | 🚨 CRITICAL 级锁 |
| 教学案例 | ~800 字 | 0 字 |
| 重复内容 | ~800-1200 字 | 0 字 |

## 四、开放问题（待讨论后确定）

1. **LAYER 1 的条目数量**：3 条还是 5 条？条目越少 → 每条注意力越强。但 M0 + ARC + M7 + WorldLaw 已经是 4 条了。
2. **LAYER 4 的压缩极限**：现在的目标是 ~1200 字。是否还能更短？哪些规则其实可以完全删除（比如"风格协议"在没有选择模仿对象时是否需要）？
3. **近因区复述的数量**：复述太多 → 变成冗余。复述太少 → 近因效应不够。目前设定为 3 条。
4. **patch 的未来**：如果后续决定恢复部分 patch，它们应该进入 LAYER 2（HIGH级）。但需要严格限制为 M0 + M4X/M5X 的 1-2 条。
5. **三重镜头模板**的位置：是 LAYER 5 的一部分，还是应该整合进 LAYER 2？
