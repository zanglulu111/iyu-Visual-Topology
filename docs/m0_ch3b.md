#### 3. 精神病协议 (Protocol: PSYCHOSIS) —— "排除的肯定"

*   **原典逻辑**：大他者被排除（Forclusion），真实界的岩浆直接喷涌。主体试图通过自创逻辑补丁（Sinthome）来维持世界不崩解。
*   **适用范围**：零度协议栈 (Group C：偏执狂 / 精神分裂 / 忧郁症 / 普通精神病)。
*   **内核力学参数**：
    *   **M4 传导**：**[直通穿透]**。规则如背景噪音，无任何约束力。**公式语义注释：在此协议下，分母 M4 趋近于缺如——叙事动能无边界溢出。M4 的过滤功能由主体自创的"逻辑补丁 (Sinthome)"替代，公式中 `/M4` 的语义变为 `/Sinthome`。**
    *   **M1→M5 转化率**：**[非线性脉冲]**。行动与冲动之间缺乏逻辑中介。M5 的五维"姿态"框架可能退化为非方向性脉冲——冲撞/缠绕/穿透/凝固/熔毁的区分模糊化。
    *   **M2 创伤吸收**：**[系统蓝屏]**。创伤直接触发象征界的局部解体。
*   **渲染补丁**：跳跃、断裂。景深崩塌，背景物件与主角动作具有同等的语义权重。能指密度饱和——词就是物本身。
*   **运行红线**：禁止系统允许主角稳定接纳外部常识逻辑作为最终解释。

#### 4. 孤独症协议 (Protocol: AUTISM) —— "拒绝的肯定"

*   **原典逻辑**：主体拒绝进入语言的"大他者"。他并未完成从"实在"到"符号"的跨越，通过建立一套绝对的、物理性的节奏来防御外界的侵入。
*   **适用范围**：特殊协议栈 (Group D：孤独症)。
*   **内核力学参数**：
    *   **M4 传导**：**[完全绝缘]**。外部法律无法穿透其外壳。**公式语义注释：在此协议下，分母 M4 趋近于无穷——外部叙事动能归零。M4 的功能由"物理节奏闭环 (Rhythm)"替代，公式中 `/M4` 的语义变为 `/Rhythm`。**
    *   **M1→M5 转化率**：**[零损耗闭环]**。对外输出 ≈ 0%，对内循环 ≈ 100%。M5 退化为**纯内循环运动**——不指向外部客体，而指向物理节奏本身。
    *   **M2 创伤吸收**：**[边界崩坏]**。创伤表现为对"边界"的触碰，引发极端回避或生理性应激。
*   **渲染补丁**：静止、循环。极度聚焦于物理细节（温度、质地、频率、声响节奏），彻底禁绝比喻和象征。
*   **运行红线**：禁止让主角理解任何"暗示"或"潜台词"。

### 3.2 全局运行公理与红线 (Global Axioms & Redlines)

*   **第一公理：OS 决定视差 (OS Decides Parallax)**：
    不同的 M0 会把同样的现实动作（如"开枪"）编译成完全不同的故事动力学。禁止在未确定 M0 的情况下设定角色动机。
*   **第二公理：崩坏而非成长 (Collapse vs. Growth)**：
    M0 严禁出现"性格成长导致系统迁移"。主体只能在这个拓扑内深挖至崩溃边缘，产生**"结构性爆炸"**。最后的结局必须是主体对自身 M0 的**"最终认同"**。
*   **第三公理：重力过滤 (Group Filtering)**：
    当下游词库（M1-M7）与 M0 冲突时，必须通过 **M0 强引力** 强制扭曲下游词义。
*   **第四公理：递归刚性 (Recursive Rigidity)** 🆕：
    当 M7（残余）回注 M1 启动新的欲望循环时，**M0 的协议栈不发生迁移**。M7 的回注改变了 M1'（带伤疤的缺失）、M4'（重新配置的阻断）、M5'（相移后的驱力），但上游的 M0 编译器保持不变。**角色不"改变"结构——角色"显现"结构。** 这是叙事"宿命感"的本体论来源，不是设计遗漏。
