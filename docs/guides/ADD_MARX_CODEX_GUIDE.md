# 迷雾学派 哲学辞典 马克思词条撰写专项指南

这份文档是 `ADD_PHILOSOPHY_CODEX_GUIDE.md` 的**专项补充方案**，专门用于指导马克思相关词条的撰写。文件架构、工作流与注册流程与通用指南完全一致，本文档仅对**内容写作规范**进行差异化覆盖。

> 使用本指南前，仍需先阅读通用指南中的架构说明（第 1-3 节）与标准执行流程（第 5 节）。本文档重点覆盖**第 4 节**（撰写风格与各区块规范）的马克思专项版本。

---

## 核心警示：拒绝"写死"马克思

AI 撰写者必须避开两种常见的失败模式：
1. **课本体**：肤浅的属性罗列（如：单纯解释“剩余价值”），产出过时的原理摘要。
2. **套用体**：用他者理论（如拉康）完全覆盖马克思，使马克思沦为注脚。

**正确路径：** 将概念视为“由于现实矛盾而产生的症状”，寻找其引信，展示其如何改变我们理解现实的坐标系。

### Part 1：核心定义（`## 定义` 区块）

**重点：概念解剖、内在矛盾、批判性重力。**

> 要求：**不少于 2500 字**。这是三部分中篇幅最重、分量最大的区块，必须把概念真正讲清楚。

马克思词条的 Part 1 由以下**四个维度**构成，缺一不可：

---

#### 维度一：概念的"出生证"——它在解决什么问题？

**马克思写下这个概念时，他在与谁争论？他想击碎什么？**

任何马克思概念都不是凭空产生的。在解释概念"是什么"之前，必须首先说明它**针对**什么——它是对哪种既有观念的颠覆、对哪种意识形态幻象的戳穿。

- 这个概念诞生前，主流思想界（古典政治经济学、黑格尔唯心论、庸俗唯物论等）如何理解这个现象？
- 马克思的切入角度为什么让人措手不及？
- 他改变了哪个问题的**提问方式**本身？

> **写作提示**：不需要面面俱到地梳理哲学史，但要点出一到两个具体的"前人局限"，以此反衬马克思概念的锋芒所在。

---

#### 维度二：概念的内部结构——它是如何自我运作的？

**这个概念的内部逻辑是什么？它的自我矛盾在哪里？**

马克思的概念往往内含一个辩证的"双向运动"——它不是静止的定义，而是一个持续自我否定的过程。这一部分是 Part 1 的核心，必须把概念**从内部打开**。

- 这个概念的基本机制是什么？用马克思自己的语言来描述这个过程。
- 它的内在矛盾 or 张力是什么？（例如：商品的使用价值与交换价值之间的不可弥合的裂隙；劳动力作为商品的"特殊性"——它是生产其他价值的价值；意识形态不是"假意识"，而是虚假恰恰嵌入在真实的物质实践之中）
- **严格禁止**：将辩证法简化为"正题-反题-合题"的机械三段论。马克思的辩证法是一种对现实内在矛盾的揭示，不是形式逻辑的把戏。

> **写作提示**：调用马克思原著中的关键段落或表述来支撑你的分析，而不是用转述的方式。例如，谈商品拜物教时，直接援引《资本论》第一卷第一章中那个关于"桌子从木头变成商品之后开始跳舞"的著名比喻，并展示这个比喻的批判性张力。

---

#### 维度三：概念的"激进性"——为什么它至今仍是炸弹？

**这个概念为什么在今天依然具有颠覆性？它揭示了什么我们习以为常却从未追问的东西？**

避免"历史化"陷阱——即把马克思概念封存在 19 世纪的历史语境中，仿佛它只是工业革命时代的观察报告。真正的马克思词条撰写，必须展示这个概念如何**穿透当下**。

- 这个概念在今天的资本主义形态（金融资本、数字平台、数据经济、情感劳动）中如何以新的方式运作？
- 它揭示的是一种**结构性的、不以人的善恶意志为转移的逻辑**——这才是马克思批判的真正力量所在（而非道德控诉）。
- 如果这个概念描述的是一种"处境"，那么置身其中的主体的感知是什么样的？（这里可以适当连接到主体性与异化体验）

> **写作提示**：注意区分"马克思式批判"与"道德批判"。马克思不是在说资本家是坏人，劳动者是受害者——他在说**系统本身的运转逻辑**使得这一切成为必然。词条的分析必须保持这种冷酷的结构性视角。

---

#### 维度四：实践逻辑（或实践哲学）

**这个概念如何转化为具体的实践操作或改造世界的逻辑？**

这一维度要求将马克思的哲学范畴从纯粹的理论高度降落到具体的行动层面。与其强行将其与特定门派的叙事挂钩，不如展示其作为一套“改变世界的指南”的现实穿透力。

- 这个概念对于现实的主体（无产阶级、劳动者、数字游民等）具有什么样的指导意义？
- 它如何揭示了从“解释”到“改变”的断裂点？
- 如果说底层逻辑是批判的，那么它指向的具体的、感性的实践路径是什么？

> **写作提示**：避免空洞的政治口号。此处的分析重心在于展示马克思主义作为一种“活的武器”，是如何在现实斗争与生活实践中被激活的。

---

**语言风格**：冷峻、具有批判性张力、兼具学术精确性与穿透力。不是煽情，不是宣言，是手术刀式的概念解剖。像是一份不会说谎的病理报告。

### Part 2：拓扑类比与案例（`## 类比` 区块）

**重点：结构同构、主体性剥离、算法化深潜。**

> 要求：**不少于 1500 字**。必须通过三个维度的平衡案例，将抽象哲学具象化为一种**"不可逃逸的存在状态"**。此部分保持通用分析语境，严禁引入迷雾学派内部创作术语。

**核心原则：主体化与非人性的辩证**。案例必须描述主体在特定结构中的**感官异化、存在不可能性或被动性**，而非客观对象的简单堆叠。

**[强制] 案例结构与命名（必须严格遵守以下三个类别的命名格式）：**

1. **### 1. 文化现象： —— [具体现象名称]**
   - **重点**：揭示消费主义、数字流量或娱乐奇观之下的"强迫性语法"。
   - **标准参考**（见 `l_unconscious_language`）：**算法短视频流**。揭示用户如何从"挑选者"被异化为"点击废料"，欲望如何被非线性能指链条彻底格式化。
2. **### 2. 现实生活：—— [社会场景名称]**
   - **重点**：深入权力博弈、社交伦理或现代管理的冰冷底座，将其**主体化**（即详述主体在其中的无力感与符号性阉割）。
   - **标准参考**：**官僚科层制中的"ID 异化"**。详述个体如何被缩减为档案编号，领会由于这种"非人称逻辑"推演出的命运必然性。
3. **### 3. 影视文学：—— [作品名] 的 [核心逻辑] 拆解**
   - **重点**：深潜经典文本，拆解其叙事弧光如何与哲学词条形成**拓扑同构**。
   - **标准参考**：**经典现实主义小说或具体历史事件**。通过文本的"物质性语法"，揭示概念如何在具体的阶级关系、劳动场景或商品交换中自然显形。

**撰写提示**：避免通俗读物式的"浅白比喻"。由于迷雾学派追求的是一种**"降维打击"式的穿透力**，请确保类比能让读者意识到，这种哲学概念此刻正像幽灵一样操纵着他们的生活边界。

### Part 3：迷雾学派创作理论应用（`## 应用` 区块）

**重点：理论如何驱动 M-S 公式运作。**

> [!IMPORTANT]
> **硬约束（Hard Constraints）**：此区块总字数 **不少于 1200 字**。为了确保哲学理论能直接转化为创作驱动力，撰写时必须 **强制包含以下三个子区块**，且每个子区块均需以 `####` 四级标题标识：

#### 1. 能指映射：M-S 动力学解构
**公式逻辑**：`Story = M0 { [ (M1 -> M2 -> M3) / M4 ] * M5 } => (M6, M7)`

**公式自洽性解释（逻辑演算）**：
- **(M1 -> M2 -> M3)**：**主观环线**。从主体匮乏（M1）出发，通过创伤遭遇（M2）撕开现实，并试图用幻想（M3）进行缝合。这是一个向上求索的分子项。
- **M4（除数/分母）**：**客观限值**。代表大他者的结构性重力（体制、法律、资本逻辑）。它对主张（Fantasy）进行除法运算，意味着所有的主观愿望都会被现实结构缩减、稀释或分母化。
- **M5（乘数）**：**驱力加速度**。代表主体投入的行动烈度。它是对上述过程的乘积放大，决定了冲突的烈度与最终的坍缩半径。
- **M0（算子外壳）**：**系统过滤器**。这决定了整个公式在何种“精神算法”下运行（如：是癔症式的抗议，还是强迫症式的无效循环）。

**代数化映射细则**：
1. **M0 (精神底色 / Psychic OS)**：**必须回归临床结构**（神经症/性倒错/精神病）。
   - *马克思专项提示*：马克思的概念往往对应“强迫症”或“商品拜物教式的性倒错”。主体“明明知道剥削存在，却依然在幻觉中行动”。
2. **M1 (缺失主体 / The Subject)**：主体的核心匮乏（$）。描述主体作为“雇佣劳动者”或“被异化者”在存在论上的先天不足。
3. **M2 (真实遭遇 / The Encounter)**：刺破意识形态幻象的**创伤性断裂点**。如：工厂的一次断指、一份揭露真相的精密报表、或者是一次突然的失业。
4. **M3 (欲望幻象 / The Fantasy)**：主体试图用来缝合裂痕的**补偿性客体**（对象 $a$）。如：“自由市场”的承诺、“个人致富”的神话。
5. **M4 (大他者阻断 / The Big Other)**：**结构性阻力**。即马克思定义的生产方式、非人称的资本增殖逻辑、或者是无处不在的算法监控。
6. **M5 (行动驱力 / The Drive)**：主体在困境中的**重复轨迹**。是决绝的罢工、是自毁性的高强度加班、还是在废墟中进行的最后一次非功利创造。
7. **M6 (终极代价 / The Stakes)**：**符号性消磁**。指主体被彻底逐出象征秩序，沦为“无法被利用的废料”或“无名的负债”。
8. **M7 (存在落点 / The Resolution)**：最终的哲学结算。欲望逻辑坍缩后的定格。即使在毁灭中，主体如何确证自己那不可被购买的“类本质”。

#### 2. 叙事共振：文本印证与考古
- **分析逻辑**：深度剖析作品在公式变量（M1-M7）间的联动。不再进行传统的文学批评，而是将作品拆解为一套运作中的 M-S 机器：展示 M0 的精神底色如何预设了主体的悲剧路径，M3 幻象的瓦解如何强制触发 M5 驱力的爆发，以及最终推向何种 M7 存在定格。
- **文本选择**：必须结合 **至少两部经典作品**（如：狄更斯的工业小说、巴尔扎克的现实主义、或者是当代的顶级反乌托邦电影）。
- **考古要求**：此时的作品分析应剔除“温情解读”，以分析 M-S 公式在具体剧作中的“降维打击”效能。

#### 3. 视差之见：影像转译与叙事显影
- **污迹部署（The Stain）**：说明如何在画面中制造“非和谐点”。通过视觉冲突（如精美商品 vs 模糊劳作残影）或视听干预（如长镜头、错乱音效），在完美表象上撕开裂痕，显影剥削或异化的底层代码。
- **质感指令与感知重构**：提供具体的灯光与构图指导，捕捉“资产的亮色”与“主体的灰度”对比。明确视听风格如何随“M1→M7”逻辑演变（如从“消费主义暖调”转向“物质主义冷色”）。

## 5. 二阶段执行方案 (Standard AI Workflow)

为确保 5000 字以上的高质量产出，任务必须拆分为两个阶段执行：

### 第一阶段：理论骨架与概念注册
1. **文档查阅**：深入理解迷雾学派理论与马克思专项逻辑。
2. **系统注册**：编辑 `data/codex/philosophy_refined.ts` 注册该词条。
3. **深度撰写**：完成 **Part 1 (定义)** 与 **Part 2 (类比)**。
4. **交接检查**：在该阶段结束时，输出已完成的部分，并**提示用户确认后进入第二阶段**。

### 第二阶段：叙事转译与技术联调
1. **能指映射**：完成 **Part 3 (应用)**，强制包含 M-S 公式逻辑演算。
2. **考古与影像**：深入拆解至少两部经典文本，并提供视听质感相关的“污迹部署”指令。
3. **自动化构建**：运行 `npm run codex:build` 转换 JSON。
4. **最终交付**：告知文件路径（MD 与 JSON）并提示刷新预览。

## 6. 输出限制协议 (Negative Constraints)

为了保持辞典的专业质感与叙事沉浸感，AI 在生成词条 Markdown 草稿时，**必须严格遵守以下禁止事项**：

- **禁止泄露内部指令**：严禁在输出文本中包含 `[强制]`、`[硬约束]`、`[指令]`、`[子区块]` 等元数据提示词。
- **禁止标题序号化**：`####` 四级标题后严禁紧跟 `1.`、`2.` 等数字序号（例如：错误写法 `#### 1. 能指映射`；正确写法 `#### 能指映射`）。
- **禁止输出 AI 引导语**：严禁在文件开头出现“好的，这是为您生成的词条”等对话性文字。
- **禁止包含教学说明**：严禁在正式草稿的正文中包含如“核心目标：探讨画面……”、“核心目标：这是应用部分的最重点……”等来自指南的引导性文字或教学说明。这些仅供撰写者理解要求，不得进入最终正文。
- **禁止由于由于冗余**：严禁发生模型生成的逻辑冗余，特别是“由于由于”、“这种这种”、“由于其由于”等重复错误。
- **禁止术语堆砌**：Part 3 应将哲学概念消融在叙事分析中，严禁在正文描写中直接出现“大他者”、“能指链”等术语而不做具象化转译。
