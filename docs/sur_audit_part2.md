## 三、 架构级发现

### 🟡 发现 1：SUR11（叙事结局）在整个第四卷 codex 中**完全没有自己的词条**

SUR11 有 8 组数据文件（group_a ~ group_h），但在第四卷的 16 篇 codex 文档中：
- 总目（4_00_1）完全没提 SUR11
- 没有独立的 `4_02_5_叙事结局.md` 或类似文档
- `4_03_3` 的缝合母段模板中，**SUR11 不在其中**

唯一认真讨论了 SUR11 的地方是 `4_05_1`（正交公理），那里主要是论证 M7 与 SUR11 的正交性。

**影响**：SUR11 作为笛卡尔乘积的关键一轴（只有它负责"故事在世界里怎么收场"），却没有自己的 codex 定义文档。AI 在阅读 codex 时，不会理解 SUR11 的设计哲学——它只会拿到 data 文件中的词条（如"拯救世界"、"天降神兵"），但不知道这些词条的使用规范和红线。

### 🟡 发现 2：4_03_3 缝合句模板中缺少 SUR11

当前的"全景动态缝合母段"是这样的（第 30-35 行）：

```
"在 [SUR3] 的 [SUR2] 场域中... 引爆了这场 [SUR1] 的悲剧。
 请遵循 [SV1]... 限制于 [SV2]... 确保支付 [M6]... 沉淀出 [M7]。"
```

**没有 SUR11。** 这意味着当前的 Payload 编译器没有显式地将"叙事结局"注入 system prompt。AI 只能从 M7（内部存在余痕）推测故事应该怎么在外部收场——这恰恰是 4_05_1 已经论证过的"两者不应该被混淆"的问题。

### 🟡 发现 3：SUR5 的"空转→坍缩"双面结构已在 codex 中定义，但 data 层没有执行

`4_02_3`（象征律令与物）第 87-89 行写得非常好——SUR5 有"前半程空转诱骗"和"后半程真相剥离"两个阶段。但在实际的 data 文件中（如 `SUR5/01_sur5_power_status.ts`），词条只有"【表面诱惑】"这一个单面。

这不是一个简单的"加字段"的问题——它涉及到 **codex 设计意图和 data 实现之间的断层**。codex 的理论是完美的，但 data 层的词条格式没有跟上。

### 🟢 发现 4：4_01_4 世界法则协议 —— 极其干净的独立模块

这篇文档（LV1-LV5 重力梯度）是整个第四卷中**最自洽、最不需要改动**的文件。它不直接引用任何 M 层术语，定义清晰，5 级划分逻辑硬朗。

## 四、 M×SUR "化学反应"的优化方向

基于全部 16 篇 codex + 10 个 SUR 数据目录的审计，我认为当前体系的"化学反应"有以下核心瓶颈：

### 瓶颈 A：SUR 层词条只有"表"没有"里"

M 层词条（经过 v3.0 重构后）已经有了 `def` + `core` + `patch.logic` + `patch.runtime` 的多层结构。但 SUR 层词条只有 `def` + `core` 两个字段——缺乏 `patch` 级别的指令注入能力。

这意味着在 Payload 编译（四级火箭第三级）时，**SUR 层词条几乎不会产生 `[HIGH]` 或 `[CRITICAL]` 级别的硬指令**。所有硬指令都来自 M 层。SUR 层只提供了"变量声明"（第二级火箭），没有自己的"执行力"。

**潜在优化**：为关键 SUR（特别是 SUR4、SUR5、SUR11）的词条增加 `patch` 字段，让它们也能注入条件触发指令。例如：

```typescript
// SUR5 词条增加 patch
patch: {
  logic: "一旦主角物理接触到此物，M6 代价切口(−Φ) 即刻生效——此物的获取成本等同于主体自身的永久性损毁。",
  runtime: "IF (主角获得此物) THEN (强制：代价必须在同一场景内显现，禁止延迟结算)"
}
```

### 瓶颈 B：缝合句模板的"单向编译"

当前的缝合句是**一次性全景声明**。它把所有参数塞进一段话里，然后 AI 就拿着这段话去写。

但更好的方式可能是**分阶段编译**——根据 SV1（叙事结构）的节拍点，在不同阶段注入不同的 SUR 参数。例如：

- 第一幕只激活 SUR2+SUR3+SUR9+SUR10（世界+主角伪装）
- 第二幕激活 SUR4+SUR5+SUR4X（大他者+欲望物+阶层阻力）
- 第三幕激活 M6+M7+SUR11（代价+余痕+叙事结局）

4_01_3（叙事遮罩）已经有了节拍映射表的雏形，但没有被实现到 Payload 编译逻辑中。
