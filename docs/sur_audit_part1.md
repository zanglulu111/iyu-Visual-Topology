## 二、 发现的致命伤 (Critical)

### 🔴 致命伤 1：SUR3 时空坐标系——整个数据目录都不存在

`data/engine_surface/` 中有 SUR1, SUR2, SUR4-SUR11，**唯独没有 SUR3**。

但是 codex「4_01_1 表层设定协议」（v5.0 宪法）明确定义了 SUR3 为**"时空坐标系 (Spacetime Coordinates)"**——"极其精确的、带有历时性的、具体时间和场域坐标"，并且它在「场域先行律」中被定义为**双轴锁定公式的第一轴**：

$$Field_{Standard} = \text{SUR3}_{\text{Era (Gravity)}} \otimes \text{SUR2}_{\text{Background (Aesthetic)}}$$

**这意味着引擎的场域锁定公式是残缺的。SUR3 是 SUR2 的正交对偶——没有它，场域的"骨架重力"轴是空的。**

**结论**：这不是"还没做到"的问题——它是一个**架构级缺失**。SUR2（背景场域，如"赛博朋克"）已经有 10 组丰满词库了，但 SUR3（时空坐标，如"2077年/夜之城"）作为其正交对偶，一条词条都没有。

> [!CAUTION]
> **建议优先级：P0。** SUR3 的缺失直接破坏了第四卷最核心的「场域先行律」。如果 AI 收不到 SUR3 参数，生成的故事将缺乏"历史重力"——所有的赛博朋克都没有具体年代质感，所有的武侠都没有朝代约束。

---

### 🔴 致命伤 2：4_01_1 协议中仍在引用已删除的 "M4X" 概念

在 `4_01_1` 第 82 行，有这段话：

```
SUR4X. 物理阶层阻力 (Social Resistance) [锚定: M4X 烈度]
```

**M4X 已经在 v3.0 中被我们彻底删除了**——引擎代码中不存在 M4X 了。但 codex 宪法级文档中仍然写着"锚定: M4X 烈度"。

同样，第 89 行的 SUR10X 虽然没有直接写 M4X/M5X，但其描述中隐含了对旧版"adjust M layer intensity"逻辑的依赖。

**影响**：AI 如果阅读这份 codex 作为 system prompt 的一部分，会被误导去寻找一个已不存在的参数。

> [!IMPORTANT]
> **建议**：将 `[锚定: M4X 烈度]` 改为 `[锚定: M4 词条谱系选择]`。SUR4X 的功能不是"调节 M4 的音量"（那是旧版 M4X 的逻辑），而是"调节社会形态在表层的粘滞度"——这本身就是 SUR 层自己的事。

## 三、 关键缺陷 (High Priority)

### 🟡 缺陷 1：SUR1 和 SUR11 的正交性尚有张力（但不致命）

`4_05_1` 第 5 节已经**极其坦诚地**指出了这个问题：SUR11（显性结局）拆得越细，它对 M5/M6 的反向规定性越强。

**实测观察**：SUR11 group_a 的词条（如"拯救世界"、"天降神兵"）确实极为具体——它们不仅指定了"好结局"，甚至指定了**好结局的物理方式**（"拔线缆"、"友军舰队劈开云层"）。这比 SUR1 的类型词条细得多。

**问题**：当 SUR11 描述得如此具体时，M6 代价切口(−Φ) 的选择空间被严重压缩。例如"天降神兵"这种结局几乎隐含了"主角不需要付出终极代价"——这和 M6 的正交性产生了摩擦。

**建议方向**：
- SUR11 的词条应当**只描述"叙事表象的结局形态"**，不应该预设"主角的代价有多少"
- 目前的 core 字段用的是"【核心爽点】"框架——这个框架**天然就在做缝合**，因为它在告诉 AI"观众应该爽"。这和 M7 的"反缝合公理"矛盾。
- **可行优化**：core 字段改用"【叙事表象】+【视差缝隙】"双面结构，前者描述"观众看到的"，后者暗示"M层可能在底下做什么"

### 🟡 缺陷 2：SUR5（欲望锚点）的 core 字段只有 A 面（表面诱惑），没有 B 面

SUR5 是 M3 幻象破绽(◇) 和 M6 代价切口(−Φ) 的换喻介质（codex 原文如此定义）。它是笛卡尔乘积中最关键的"交叉点"之一——因为它**同时触碰了 M 层和 SUR 层**。

但目前 SUR5 的所有词条的 core 字段格式都是：
```
core: "【表面诱惑】：xxx"
```

只有 A 面（"这个东西为什么诱人"），**完全没有 B 面**（"这个东西在引擎学看来真正承载的是什么？"）。

相比之下，SUR1 的 core 字段有换喻标记（`换喻($): 秩序`），这至少建立了一条从 SUR → M 的翻译线索。但 SUR5 完全没有。

**风险**：AI 拿到 SUR5 词条后，只会生成"获得宝物有多诱人"的表层叙事，不会自动激活 M6 的代价逻辑——因为词条本身没有给出任何"代价暗示"。

**建议方向**：
- 为 SUR5 的 core 字段增加 B 面：`【本体论代价】：xxx`
- 示例：`"染血的最高王座"` → `core: "【表面诱惑】坐上去就是万人之上。【本体论代价】权力的光环即枷锁——它不让你走。坐上去的同时，你的退路被烧尽。"`

### 🟡 缺陷 3：SUR1 的"换喻($)"标记不够精确

SUR1 每条词条的 core 末尾都有这个：`换喻 ($): 秩序` / `换喻 ($): 掌控`。但：
1. **($) 没有在任何 codex 文档中被定义**——它是什么符号？为什么是 $？和 M1 缺失($) 的 $ 是同一个吗？
2. **换喻的指向太宽泛**——"秩序"、"掌控"、"边界"这类词太抽象，无法有效引导 AI 在 M 层选择对应的词条

**建议方向**：
- 明确定义：这个 `$` 是 M1 的缺失符号，表示"这个类型背后隐藏的缺失主题"
- 把换喻指向从"一个词"扩展到"M 层的具体锚点说明"，例如：`换喻 → M1 缺失坐标: 秩序的丧失 / M4 最近亲和词组: A组(不可见体制)`
