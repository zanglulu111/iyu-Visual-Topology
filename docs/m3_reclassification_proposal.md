# M3 欲望幻想 — 拓扑学重分类方案

> [!IMPORTANT]
> **核心原则**：M3 的分类维度不应该是"幻想的内容"（归乡/复仇/逃跑），而应该是**"幻想的拓扑运动方向"**——即主体($)相对于客体小a的位移矢量。
>
> 这与 M1 按"主体位置"（被吞没/迷失/被驱逐）、M2 按"穿刺类型"（秩序/认知/肉身/关系）重命名的逻辑完全一致。

---

## 一、旧分类的问题诊断

| 旧分组 | 问题 |
|--------|------|
| A. 修复幻想 (Restoration) | 描述了"做什么"而非拓扑位移方向。20条词条已有张力格式,但分组名本身缺乏拓扑学深度 |
| B. 获取幻想 (Acquisition) | 同上。"获取"是日常语义,不是拓扑坐标 |
| C. 连接与融合 (Connection) | 24条旧格式,且分组名混合了两种不同的运动——"连接"(向他者运动)与"融合"(消解自我边界) |
| D. 逃逸与虚无 (Escape) | 24条旧格式,且"逃逸"与"虚无"是两种截然不同的拓扑操作——前者是主体的位移,后者是主体的消解 |

**根本问题**：旧的 A-D 分组是按**幻想的"内容题材"**分类（修啥补啥/抢啥拿啥/找谁抱谁/往哪跑），而不是按**主体相对于缺失(M1)和对象a(objet a)的拓扑运动方向**分类。

---

## 二、新分类方案：幻想的五种拓扑运动

M3 的本质是：在 M2（真实遭遇）撕开幻象之后，主体($)编织的一种**"如何绕行客体小a而不坠落"**的剧本。

从拓扑学角度看，主体只有**五种**可能的运动方向：

```
                        朝向缺失
                           ↑
                           |
        ┌──────────────────┼──────────────────┐
        |                  |                  |
   E. 溶解边界    A. 倒转时间线        B. 直取对象
   (Dissolve)    (Reverse)           (Seize)
        |                  |                  |
        └──────────────────┼──────────────────┘
                           |
                   C. 绕行替代路径
                   (Reroute)
                           |
                   D. 脱离轨道
                   (Exit Orbit)
                           ↓
                        远离缺失
```

> **关键张力公式**：如果缺失本身被撤销——主体还是主体吗？（因为是缺失定义了主体）

## 四、设计原理说明

### 4.1 为什么是五组而不是四组？

旧的 C 和 D 各自包含了**两种拓扑性质完全不同的运动**：

- 旧C **"连接与融合"**：
  - "连接"（通过他人间接接近对象a）= 新C **绕行**
  - "融合"（消解自我边界成为一体）= 新D **溶解**
  
- 旧D **"逃逸与虚无"**：
  - "逃逸"（从轨道脱离）= 新E **脱轨**
  - "虚无"（消解到零）= 部分归入新D **溶解**

将它们混在一起会导致引擎对"幻想方向"的判断模糊。拆分后，每个分组的拓扑矢量是**单一且明确的**。

### 4.2 与 M1 和 M2 分类学的同构性

| 模块 | 分类维度 | 逻辑 |
|------|----------|------|
| M1 缺失 | **主体的位置** | 被吞没/迷失/被驱逐/断裂/空洞/过剩 |
| M2 遭遇 | **穿刺的类型** | 秩序/认知/肉身/关系/边界 |
| M3 幻想 | **运动的方向** | 倒转/夺取/绕行/溶解/脱轨 |

三个模块的分类学现在共享同一个底层逻辑：**按拓扑结构分类，不按内容题材分类**。

### 4.3 新分组名称的中性化

遵循"除恶务尽"行动的宪法级原则：

- ❌ "修复" → 暗示"东西坏了" → 暗示原状态是"正确的"
- ✅ **"倒转"** → 中性动作描述，不预设倒转是好是坏

- ❌ "逃逸" → 暗示"逃跑=懦弱"  
- ✅ **"脱轨"** → 中性描述，脱轨可以是觉醒也可以是崩塌
