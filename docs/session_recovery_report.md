## 四、关键设计原则备忘

以下是在清洗过程中确立的、后续必须遵守的宪法级原则：

### 4.1 词条 core 的格式标准

```
A面：[温柔/正向的可能性——this could be...]
B面：[沉重/暗面的可能性——but it could also be...]
关键张力：[不给答案的追问——the question that stays open]
实在界穿刺($)：[不可回避的结构性真相——the structural truth]
```

- 中文字符目标：**~150-180 字**
- 禁止单维度暗调
- 禁止学术腔（拉康/大他者/阉割）

### 4.2 分类学命名原则

- 旧原则：按**现象** 命名（"异化""废墟""背叛"）→ 暗示已经毁灭
- 新原则：按**主体位置**命名（"被吞没""迷失""断裂"）→ 中性拓扑坐标，不预设结局

### 4.3 引擎本体论修正

```diff
- 世界的本质 = 创伤 (Trauma)
- 主体的本质 = 受难者 (Sufferer)
- 欲望的本质 = 骗局 (Trap)
- 结局的本质 = 灰烬 (Ashes)

+ 缺失不是诅咒，欲望不是疾病，运动不是逃亡。
+ M1 是引擎，不是刑具。
+ 引力恒温的目标不是"保持痛苦"，而是"保持运动"。
```

### 4.4 关于"治愈"的辩证立场

- ❌ **不允许**：廉价治愈（用外部事件修补空洞）
- ✅ **允许**：穿越幻象（认清空洞，带着它前行 → "和解"）
- 温暖的结局在美学上是合法的，只要空洞的结构完整性被保持
