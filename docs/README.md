# 文档索引

`docs/` 存放项目说明、归档材料、数据库脚本和本地检查报告。根目录只保留应用入口、配置和必须被工具直接读取的文件。

## 主要入口

- `PROJECT_MAP.md`：项目结构、数据流、维护边界和协作流程。
- `database/`：需要人工执行或迁移参考的数据库脚本。
- `reports/`：本地检查报告、历史错误输出和整理记录。
- `archive/`：旧计划、旧原型、临时实验和历史材料。

## 内容主线

- 哲学与迷雾学派草稿仍以 `../codex-drafts/` 为源。
- 前端可读取的词条 JSON 仍以 `../public/data/codex/` 为输出。
- 项目专用 Codex 技能仍以 `../.agents/skills/` 为准。
