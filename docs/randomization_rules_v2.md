## 二、故事摘要 12 词的加权筛选机制

### 故事摘要句式

> 在【时空坐标 SUR3】的【背景场域 SUR2】世界中，运行于【阶层阻力 SUR4X】下的【社会形态 SUR4】社会体系之下，一个【性别 SUR7】【职业身份 SUR9】，抱着【缝合度 SUR10X】的【哲学信念 SUR10】想法，与【欲望锚点 SUR5】纠缠，剧情于【空间场景 SUR6】展开，最终走向【显性大结局 SUR11】的故事。

> [!IMPORTANT]
> **核心规则：全局随机时，故事摘要12词最多只有6个参与随机，通过加权概率筛选。**

### 12 词的权重分配

| 参数 | 权重等级 | 参与随机的概率 |
|------|:-------:|:-----------:|
| SUR1. 叙事动力 | **高** | 65% |
| SUR2. 背景场域 | **高** | 65% |
| SUR3. 时空坐标系 | **高** | 65% |
| SUR7. 主体性别 | **高** | 65% |
| SUR9. 职业身份 | **高** | 65% |
| SUR5. 欲望锚点 | **中** | 50% |
| SUR4. 社会形态 | **低** | 30% |
| SUR6. 空间场景 | **低** | 30% |
| SUR10. 哲学信念 | **低** | 30% |
| SUR11. 结局 | **低** | 30% |
| SUR4X. 物理阶层阻力 | **低** | 30% |
| SUR10X. 象征界缝合度 | **低** | 30% |

### 概率计算

```
高权重 (5个): 5 × 0.65 = 3.25 个（期望入选数）
中权重 (1个): 1 × 0.50 = 0.50 个
低权重 (6个): 6 × 0.30 = 1.80 个
────────────────────────────────
总期望入选数 = 5.55 个 ≈ 6 个（天然接近上限）
```

### 筛选算法
```
Step 1: 遍历12个参数，各自独立按权重概率 roll 骰子
         → 高权重 roll < 0.65 则入选
         → 中权重 roll < 0.50 则入选
         → 低权重 roll < 0.30 则入选
Step 2: 互斥规则——若 SUR2 和 SUR3 同时入选，随机保留一个
Step 3: 若入选数 > 6，按优先级淘汰（低权重先淘汰，同级随机淘汰）
Step 4: 对最终入选的参数执行实际随机（从词库中抽取词条）
Step 5: 未入选的参数保持当前值不变（不清空）
```

## 三、特殊规则

### 规则 1：SUR7 性别偏置
随机生成性别时：
- **女性概率 70%**
- **男性概率 30%**

### 规则 2：SUR2 / SUR3 互斥
SUR2（背景场域）和 SUR3（时空坐标系）在随机逻辑下是 **OR** 关系：
- 只能随机到其中之一
- 若均被权重筛选入选，随机保留一个，另一个剔除出本轮随机

### 规则 3：上限约束 (Cap = 6)
故事摘要 12 词中，**每次随机最多只有 6 个词被刷新**。其他词条保持当前状态。

## 四、三级随机级联体系

### Level 1: 个体随机（单词条随机）
触发：点击某个已选词条下方的🎲按钮

```
行为：仅随机当前词条所属的单个 blockId
规则：
  - 从该 blockId 对应的词库中抽取新词条
  - 抽取数量遵循"随机可选区间"列
  - 尊重锁定状态（locked tags 保留）
  - SUR7 遵循 70/30 性别偏置
  - 不触发权重筛选（因为已经指定了目标参数）
```

### Level 2: 局部随机（模块组随机）

#### 2a. 表层设定组随机
触发：点击"表层设定"标题旁的🎲按钮

```
行为：仅随机表层设定（SUR系列 + SV系列 + 调音台推子）
规则：
  - 执行 12 词加权筛选（Step 1~5）
  - 入选参数按其"随机可选区间"抽取
  - 上限 Cap = 6
  - 未入选参数保持不变
  - 尊重所有锁定（模块锁 + 词条锁）
```

#### 2b. 核心公式组随机
触发：点击"核心句式"标题旁的🎲按钮

```
行为：仅随机 M0-M7 引擎核心 + M4X/M5X
规则：
  - M0, M7 必须随机（必填·唯一）
  - M1-M6 按"随机可选区间"的 1-2 范围随机抽取数量
  - M4X, M5X 各 50% 概率参与（0-1）
  - 尊重锁定
```

#### 2c. 故事结构/摘要组随机
触发：点击"故事结构"或"故事摘要"旁的🎲按钮

```
行为：对应组内参数执行局部随机
规则：
  - 故事结构组：skin_structure (SV1), skin_volume (SV2) 各独立随机
  - 故事摘要组：触发 12 词加权筛选
  - 均遵循 Cap = 6
```

### Level 3: 全局随机（整体一键随机）
触发：点击侧边栏最顶层的🎲按钮

```
行为：同时随机 M0-M7 + 表层设定 + 调音台 + SV
规则：
  Step 1: 先随机 M0-M7 引擎核心（同 Level 2b）
  Step 2: 再执行 12 词加权筛选（同 Level 2a）
  Step 3: 时空坐标 SUR3 独立随机年份(-2000~2050)和国家
  Step 4: 执行 SUR2/SUR3 互斥裁决
  Step 5: SV1/SV2 各 50% 概率参与
  Step 6: 所有被锁定的模块/词条完全跳过
```

## 五、概率分布深度分析

### 加权筛选后的期望分布

| 入选数 k | 大致概率 P(X=k) | 说明 |
|:--------:|:--------------:|------|
| 0–2 | ~2% | 极端冷淡（几乎不可能） |
| 3 | ~8% | 少数核心被选中 |
| 4 | ~18% | 偏保守：主要是高权重 |
| **5** | **~28%** | **最高频区间** |
| **6** | **~25%** | **次高频，触碰上限** |
| 7+ | ~19% | 超出上限→自动裁剪至6 |

> [!NOTE]
> 期望入选数 μ = 5.55，标准差 σ ≈ 1.63。约 44% 的情况下入选数 ≤ 5（无需裁剪），约 19% 的情况下需要从超量候选中淘汰至 6。

### 单参数的最终被随机概率（含 Cap 裁剪影响）

| 权重等级 | 原始入选率 | 裁剪后有效率（近似） |
|:------:|:--------:|:--------------:|
| 高 (65%) | 65% | ~60% |
| 中 (50%) | 50% | ~45% |
| 低 (30%) | 30% | ~25% |

> 裁剪主要影响低权重参数。当总入选数超过6时，优先剔除低权重候选，因此低权重的实际命中率被进一步压缩约5个百分点。
