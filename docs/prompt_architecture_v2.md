# 📐 迷雾学派 Prompt 指令架构 V2.0
## 回归本质：五区块融合架构

---

## 核心需求（一句话）

> **让 AI 理解核心公式，穿上表层皮肤，遵守世界法则，按叙事结构讲一个完美故事。**

就这五块：

```
┌────────────────────────────────────────────┐
│  BLOCK 0: 身份 (一句话)                      │
├────────────────────────────────────────────┤
│  BLOCK 1: 核心公式 (M0-M7)                   │  ← "故事的灵魂是什么"
│  公式位置关系 + 当前具体值 + 走向判定            │
├────────────────────────────────────────────┤
│  BLOCK 2: 表层设定 (SUR1-11)                 │  ← "灵魂穿什么皮"
│  当前场域 + 时空 + 身份 + 转译任务              │
├────────────────────────────────────────────┤
│  BLOCK 3: 世界法则                           │  ← "这个世界什么能做什么不能做"
│  物理约束等级 + 类型融合规则                    │
├────────────────────────────────────────────┤
│  BLOCK 4: 叙事结构 & 输出 (SV1-2)            │  ← "怎么讲、讲多少、吐什么格式"
│  体量 + 结构 + JSON 模板                     │ 
├────────────────────────────────────────────┤
│  BLOCK 5: 创作铁律 (压缩禁令)                 │  ← "什么绝对不能做"
│  命名 + 美学 + 禁用词                        │
└────────────────────────────────────────────┘
```

## BLOCK 1: 核心公式（~800字 | 关键中的关键）

这是整个 Prompt 最重要的部分。分两个子区：

### 1A. 公式位置关系说明（~350字 | 静态）

> [!IMPORTANT]
> 这部分解决你的第一个疑问：**AI 是否真正理解每个 M 参数在公式中的位置和拉康含义？**
> 这 350 字必须写死在每次发送中，因为这是引擎的灵魂。但只说"位置是什么"、"做什么"，不说"为什么"。没有案例。

```markdown
## ⚙️ 核心公式：欲望的代数

**Story = M0 { [(M1 → M2 → M3) / M4] × M5 } ⇒ (M6, M7)**

你不是在写作文，你是在**解这个方程**。每个参数是一个拓扑位置，不是词汇：

**M0. 精神拓扑（定义域/操作系统）**
→ 不是具体设定，是故事的因果律。它决定了公式内一切运算的法则。

**M1. 缺失主体（分子/被除数）**
→ 主体的核心匮乏。它是承受者。必须结合 SUR9(职业) 具象化。

**M2. 真实遭遇（分子/撞击）**
→ 打破日常幻象的暴力事件。没有 M2，主体将永远停在 M0 的平庸秩序中。

**M3. 欲望幻想（分子/诱饵）**
→ 主体认为能填补 M1 缺失的那个东西。它是驱动力，也是骗局。

**M4. 大他者阻断（分母/除数）**
→ 结构性阻力。它不是为了吓人，是为了**阻挡 M1 获得 M3**。
→ 它必须精准攻击 M1 的弱点。M4 越大，M1 的意义越被压缩归零。

**M5. 行动驱力（乘数）**
→ 主体对抗 M4 的具体姿态。它是动作的烈度。
→ M5 不关心 M4 有多大，驱力的本质是盲目的机械性重复。

**M6. 终极代价（结项报告/配平）**
→ 为了让公式闭合，必须从主体身上切除的等效质量。比死更可怕的东西。

**M7. 存在落点（余数/沉淀）**
→ 公式除不尽的那个部分。它不是答案，是灰烬中发亮的舍利。
→ **M7 是绝对宪法。用户选了什么，你就写什么。严禁篡改。**
```

### 1B. 本次具体值 + 走向判定（~450字 | 全动态）

> [!NOTE]
> 这部分是每次生成都不同的。把每个 M 参数的当前值、Definition、Core 列出来，
> 并在最后注入 NARRATIVE_ARC 走向判定和 M0 的精准逻辑约束。

```markdown
## 🧬 本次 DNA 序列

* **M0. 精神拓扑**: [完美的门面]
  Def: 生活在精致的假象中，拒绝承认墙后就是荒原。
  Core: 只要天鹅绒还没褪色，世界就是安全的。
  🚨 **M0 逻辑约束**: 主体运行在"否认"铁律下。叙事前3/4严禁让主体
  承认假象的崩塌。天鹅绒褪色的裂缝只允许在高潮点出现。

* **M1. 缺失主体**: [割裂的缝合体]
  Def: 由截然不同的身份/信念残骸强行拼凑而成的个体。
  Core: 我的体内缝补了太多不兼容的碎片……

* **M2. 真实遭遇**: [无法逃逸的UI] + [双重脉搏]
  Def: 发现自己的伤口愈合受控于视线边缘的进度条... / 发现自己有两个心脏
  Core: 肉体的介面化 / 非人感

* **M3. 欲望幻想**: [终结]
  Def: 渴望停止存在，寻求永久的安息。

* **M4. 大他者阻断**: [无名审判团]
  Def: 没有面孔的集体投票机。按处决按钮无需担责。

* **M5. 行动驱力**: [游击战]
  Def: 在暗处进行骚扰、破坏和消耗。
  Core: 只要我不现身，我就无处不在。

* **M6. 终极代价**: [身份顶替]
  Def: 另一个肉体合法继承了你的所有能指，你变成冗余副本。

* **M7. 存在落点**: [虚无的失忆]  🚨 绝对宪法
  Def: 主脑切除了主体所有痛苦与反抗的记忆，重置为快乐白痴。

### 张力走向判定
🚨 **NARRATIVE_ARC = [DEADLOCK]**
→ 保持最大戏剧张力。终幕前不得解决冲突。双方承受对等损耗。

### 压迫与驱力视差
* **M4X 压迫烈度**: L5.绝对暴力 → 大他者动用最高合法暴力，物理碾压。
* **M5X 驱力流速**: L4.爆发/行动 → 主角在某个节点砸烂一切体面保护壳。
```

## BLOCK 3: 世界法则（~150字 | 半动态）

```markdown
## ⚖️ 世界法则

**物理法则**: LV.3 缝合 / MAGICAL REALISM
→ 以残酷现实为底，允许局部缝合超现实的符号与症状。
→ 正常与荒诞通过视差共生。超现实部分伴随巨大代价。

**语境法则**: GENRE FUSION (CONTROLLED MASHUP)
→ 浪漫喜剧 + 高科技犯罪。跨类型融合必须受控，不可变成无逻辑拼盘。

🚨 **任何违反此法则的生成判定为失败。**
如果物理法则为 STRICT REALISM，严禁出现魔法/鬼魂/超光速。
```

## BLOCK 5: 创作铁律（~600字 | 静态 · 极度压缩）

```markdown
## 🔒 创作铁律

### 命名
- 严禁通用名（Tom/Alice/小明/李华）。严禁单字名。
- 默认国际化 → 无中国风标签则严禁中文名。
- 电影级真实。严禁网文中二词（钨神/影刃）。
- 严禁 AI 惯用套路（决明/步虚/渡鸦/老鬼）。
- 必须基于 SUR3+SUR2 当场构思独特真名。

### 美学
- 沾染：在无菌中找有菌裂痕，或在有菌废墟中找无菌秩序。
- 光影：每段描写必含光影。拒绝平光。
- 触觉：强调材质对比与温度。
- 隐喻实体化：痛苦必须转为物理环境变异。
- 陌生化：描述质感/光泽/异样感，不直呼物名。

### 绝对禁令
- 严禁正文出现 M0-M7 标签原词。消融在感官描写中。
- 严禁学术腔（拉康/大他者/异化/阉割/符号界/对象a）。
- 严禁理工腔（算法/逻辑闭环/精准计算）。
- 古代背景下现代词必须概念降维（算法→天道/宿命）。
- 情节必须经历否定→否定之否定→扬弃。
- 暴力须有仪式感/雕塑感。避免医学解剖式描写。
- 模仿风格时模仿底层逻辑，严禁堆砌表层符号。
- 面具协议：故事必须首先作为合格类型片运作。

### 动态禁用词
[黑名单: 所有标签原词 + 学术术语列表...]

### 输出禁令
- 严禁剧本格式（内景/外景/日/夜）。
- 严禁学术论文腔、教科书旁白、鸡汤散文、网络小说腔。
- 严禁机械降神、无冲突流水账。
```

## 与旧架构的对比

| 问题 | 旧架构 | 新架构 |
|---|---|---|
| AI 是否理解公式 | 公式说明散落在多处，被案例稀释 | **BLOCK 1A 集中 350 字精要说明** |
| M0-M7 的位置关系 | 有但混杂了大量教学案例 | 纯位置/功能定义，零案例 |
| SUR 的处理 | 每个都解释锚定关系 | 用到的才列，不用的跳过 |
| 核心需求 | 被大量"铁律"淹没 | 5 区块清晰对应 5 个需求 |
| 总字数 | ~5000-6000 | ~2500 |
