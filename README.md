# 【迷雾学派】爱欲视觉拓扑学 (Visionary Eros Topology)

这是一部集合了精神分析（拉康）、辩证法（黑格尔）、政治经济学（马克思）以及齐泽克激进理论的视觉拓扑学辞条系统。

## 🚀 快速开始

1. **核心引导**：请首选阅读 [🚀_立即开始_READ_ME_FIRST.txt](./🚀_立即开始_READ_ME_FIRST.txt)。
2. **本地运行**：
   - 安装依赖：`npm install`
   - 配置环境：设置 `GEMINI_API_KEY` 于 `.env.local`
   - 启动应用：`npm run dev`
